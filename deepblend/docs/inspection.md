# 固定视角检查与创作引导

当作品显得粗糙时，先固定相机和帧，再分别看灰模与材质检查图。
灰模适合找比例、轮廓、倒角和接缝问题；材质检查图用于观察反射、透明度、颜色和接触阴影。
检查图帮助定位问题，最终质量仍需要结合目标与参考图审阅。

## 从工作台完成一次检查

1. 在项目中保存目标、参考图和主要评审对象。可从配方开始，也可从[素材库](assets.md)导入自己的模型。
2. 在场景树中修改对象。先保存或放弃草稿，再打开“预览”。
3. 在“固定视角检查”选择一个已有相机、范围内的整数帧、显示方式和采样数。
4. 生成“中性灰模”，检查整体比例和接缝。需要看小倒角时，选择已有特写相机；缺少机位可通过 Agent 或场景补丁添加。
5. 保持相机、帧和采样数，生成“材质检查图”，观察材质与照明。对照时核对实际设置和来源版本。
6. 修改问题后保存新版本，再用相同条件复查。旧图保留在它自己的版本下，不会自动变成新版本的证据。

“创作引导”提供目标参考、起点、部件、灰模、细节、材质灯光和交付入口，可随时跳转。
这些入口不会自动提交修改或运行渲染。动画应覆盖实际关键动作及均匀采样帧，单张检查图不能证明整段运动正确。
原有“多视角预览”、联系表、QA 和最终交付仍使用各自的产物。

## 灰模的含义

灰模由所选版本的 SceneSpec 重新编译：保留几何、对象/相机/骨骼动画、灯光和 world，
将未标记 `environment` 的非 empty 实体替换为固定不透明灰色材质，移除它们的部件材质绑定。
环境实体保留原材质。原材质动画仍存在于派生文档中，但不会重新控制已替换的灰色表面。

- 灰模会移除被替换表面的透明、发光、颜色纹理、法线和凹凸效果；透明叶片卡片可能显出原来的承载平面。
- 去掉反射、透射和发光会改变光线传播。相同摄影设置不代表相同光照结果。
- 导入材质中的着色器位移可能影响最终几何；重新编译的检查图不等于直接渲染原 checkpoint。
- 灰模不能证明壁厚、封闭性、无自交，也不会写入“艺术通过”的结论。

第一版支持 Cycles / EEVEE，最多 8 个视图、每边最多 2048 像素；采样数受预览预算限制。
工作台每次选择一个相机/帧。缓存物理场景会明确拒绝，以免重新烘焙后误称与原结果等价。
隔离资产支持无内嵌相机/灯光的自包含 GLB、PNG/JPEG、HDR/EXR、STL 和 PLY。
需要外部依赖的其他格式可继续使用原有 checkpoint 预览。

## API 与存档

Host API 6 扩展现有 `renderViews`：

```js
await studio.renderViews({
  projectId: 'my-project', revision: 'r0002', mode: 'clay',
  views: [{ id: 'selected', cameraId: 'camera-main', frame: 24 }],
  samples: 32, signal,
})
```

显式 `mode: 'beauty' | 'clay'` 均走独立派生编译和 batch 渲染；不传 `mode` 保留原有多视角预览行为。
所选 revision 必须明确。旧 Host 不支持该模式时，UI 会提示重启，不能静默退回成品渲染。

每次成功任务保存在 `revisions/<revision>/diagnostics/<unique-job-id>/`，包含 PNG、
`derived-scene-spec.json` 和 `result.json`。列表通过 `listPreviewSets().revisions[].diagnostics` 返回，
与默认 previews、contactSheets 和 reviews 分开。全部图片解码与实测信息通过后才发布；失败和取消不发布半套图片。

回执记录原 SceneSpec 字节/语义摘要、原 checkpoint 摘要（不存在时为 null）、实际复制的资产摘要、
派生 SceneSpec/checkpoint 摘要、变换版本及每图实际相机矩阵、光学参数、帧、渲染设置和 PNG 摘要。
派生 checkpoint 和私有资产副本在结束后删除；保留派生文档以便审计和重建。

当前界面不会自动认定两张图可比。跨版本比较还需确认相机、灯光、world、资产输入和实际渲染配置一致；
全景相机或骨骼对焦子目标的记录尚不足以证明完整摄影条件相同。

## 验证范围

- Host 契约覆盖原文件保护、非法参数、缺图/坏图/错误实测信息、失败、取消、重试和资产 hash 变化。
- 真实 Blender 集成验证三帧姿态、多槽导入模型、共享材质环境与主体、派生场景的几何和材质。
- 浏览器验收检查实际图片、刷新后的独立历史、未保存草稿与取消。

这些工程检查不代替非维护用户用自己的素材完成作品，也不代替参考图和人工美术审阅。
