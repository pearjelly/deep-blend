# 比较配方，保留各自的调整

在工作台「项目」页选一个配方，调整颜色、粗糙度或曝光。再选另一组作品查看和调整；返回原配方时，之前的参数仍在。再次点击「已选择」不会重置。手动填写的作品名称与目标也保留。

- 「恢复配方默认值」只重置当前配方，其他配方的调整保留。
- 空白项目不使用配方，但可以返回之前的配方继续。
- 留空或超出范围的数值仍会保留，界面提示修正，创建按钮不可用；不会悄悄换成零或默认值。
- 示例图片始终展示配方默认设置；选择和比较不创建项目、不自动重渲染。点击「创建并生成预览」后，才按当前选中的完整输入创建并渲染。

## 稍后继续

比较设置随当前浏览器的创建草稿一起保存。刷新或重新打开后，明确选择「继续这份草稿」，再切换配方检查此前设置。恢复不会自动提交。保存范围、页面隔离、容量提示和删除操作见[创建草稿](creation-drafts.md)。

「清空当前创建草稿」同时清理本页保存的各配方调整；不清理其他页面或项目。成功创建只消费已确认的那组输入，其他未提交配方或后来修改的设置仍可继续。

## 配方有新版本

设置按配方身份、版本与内容摘要分别保留。新的版本或改变的配方使用自己的默认值，不继承另一份内容的参数。原配方不可用时仍保留旧记录；不能用旧记录替当前配方创建。原创建请求的明确重试继续使用当时输入，比较或重置不会修改它。

旧版浏览器草稿仍可恢复原先选中的输入，恢复后再比较也会分别保留。损坏或不明确的比较记录会被拒绝，原记录保持，用户可以明确删除或清空。
