# 保存预览图片

从作品配方或自己的场景生成预览后，点击图像上方的「保存预览 PNG」。完成准备时会显示「已交给浏览器保存」与文件名；文件位置及最终保存由浏览器管理。

最新预览、上一次与本次渲染、版本对照、拼图、固定机位的材质/灰模检查和摄影编辑结果都有独立保存入口。文件包含项目、实际源版本、相机或检查模式、可用帧号和图片摘要。查看旧版本时，文件名使用那张图的版本。重复保存相同图片时，浏览器可能覆盖或重命名已有文件。

保存保留原始 PNG 的尺寸、采样和像素，不会重渲染、修改场景、创建版本或视频任务，也不需要 FFmpeg/ffprobe。需要更大的尺寸或更高采样时，先通过渲染任务生成相应图像；保存按钮不会改善已有预览的质量。

工作台读取所选图片并核对记录的字节数、PNG 标识、已有尺寸和完整 SHA-256。局域网 HTTP 没有原生浏览器加密 API 时也可以校验。图片路径被后续预览复用而内容已变时，本次保存会拒绝；刷新查看最新来源后再保存。旧记录缺少完整摘要或字节数时，生成新预览后即可使用。

准备过程可取消；30 秒仍未完成会停止准备并允许重试。取消生效后不会交给浏览器保存。浏览器已经接收文件后的取消或最终写盘由浏览器管理。

安装前可运行 [环境自检](environment-check.md)；首次创作入口见 [快速上手](quick-start.md)。
