# 重载后继续创建草稿

工作台把尚未完成的创建输入保存在当前浏览器。重载或重新打开同一工作台后，在「继续创建草稿」选择一份草稿，点击「继续这份草稿」。恢复只填写输入，不会自动创建项目。

- 名称、目标、配方身份与参数一起保留。比较过的配方各自保留调整，恢复后可以切换回来继续；见[配方比较](recipe-comparison.md)。恢复之前仍可检查已保存项目的列表。
- 上次创建回执尚未确认时，恢复同时保留原请求。点击「重试上次创建」会检查同一次创建，已保存的作品会直接打开，不另建或再次渲染。
- 后来输入的新名称与参数独立保留。重试仍使用上次点击时的输入，成功后不会清除后来编辑的草稿。
- 多个页面各自保存草稿。恢复一个仍打开页面的草稿会建立独立副本；已正常离开的页面，其未被修改的记录在副本成功保存后移交给当前页面，避免反复恢复不断堆积副本。

## 已有配方发生变化

草稿使用配方 ID、版本与摘要匹配当前配方库。不能匹配时，界面会说明原配方当前不可用，并保留原参数供查看。原请求仍可重试，以恢复已经创建的项目；新建作品前需要明确选择当前配方或空白项目，不会悄悄替换成默认值。

## 清理草稿

「清空当前创建草稿」清空当前页面的创建输入、各配方的比较设置与请求。「删除浏览器草稿」只删除明确选择的浏览器记录。两者都不删除项目、图片、作业或版本。创建仍在进行时不能清空当前请求。

已确认完成的原输入会被清理，较新的未提交输入会继续保存。其他页面后来修改的记录不会被旧请求的成功回执清除。

## 保存范围与异常

草稿按工作台实际使用的项目存储隔离，保存在当前浏览器的本地存储。它不是云端备份；更换浏览器配置、设备、地址、端口或清理浏览器存储后，不能承诺仍能读取。项目文件仍由 Host 保存在磁盘中。

每个项目存储最多保留 20 份浏览器草稿，包含各配方设置的单份 JSON 最多 256 KiB。存储不可用、容量已满、输入过大或记录损坏会明确提示，当前内存输入仍可继续使用。不会自动截断输入或删除其他草稿；无法读取的记录可明确删除。浏览器被强制终止而没有正常离开事件时，可能保留需要手动整理的旧副本。
