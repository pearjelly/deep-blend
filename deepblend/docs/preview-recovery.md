# 切换项目与预览读取恢复

在“项目”选择作品后，“预览对比”只显示该作品的已保存图片。等待读取期间不会沿用上一个作品的图或下载地址。

如果读取失败，页面显示原因和“刷新”按钮。刷新只重新读取，不创建项目、不保存编辑，也不重新渲染。恢复后可保存该作品的原始 PNG；没有预览图片的版本仍需明确点击“渲染预览”。

读取失败时，已保存的场景、版本与 PNG 保持不变。未提交编辑也保留；返回原项目后可以继续调整。若先前明确恢复了另一个保存版本，旧版本草稿的冲突提示仍需按页面指引明确处理，刷新不能自动解决版本冲突。

如果显示预览来源不匹配，刷新后重试；若仍出现，请导出诊断并提交问题。Host 协议不匹配则沿用页面的重启指引。

版本选择与只读对照见[版本对比](version-comparison.md)，安装与环境检查见[安装指南](install.md)。
