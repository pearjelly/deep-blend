# 给作品制作一段相机运动

从新建作品开始时，先看[台灯完整首作](first-product-creation.md)。本页说明已有场景的镜头操作。

此流程适合已有产品场景、希望从一个完整静态机位制作短促推进或拉远的创作者。先在「调整」中检查产品尺寸和摆放，再按下文准备交付画幅与完整取景，最后在「导出」中找到「制作相机推进」。当前能力只添加相机运动，不自动制作产品变形、角色表演或完整影片剪辑。

计划交付 16:9 时，先到「导出 → 为 16:9 交付准备画幅」检查预览和正式尺寸；若不是 16:9，点击「保存 16:9 画幅」。这会另存一个版本，将两个配置改成 16:9，尽量保留原宽度且不增加像素总量；模型、相机、采样及旧版本保留。画幅改变会影响构图，必须在新版本重新进行完整取景并看图。若有未保存的编辑或运动草稿，先保存或重置；输入尺寸太小或配置不可读时无法自动转换。

如果直接选择 16:9 图片或视频预设，而工程的预览或正式画幅不同，导出表单会提示可能裁切；无法读取配置时会提示无法确认。提醒不会自动修改画幅，也不能替代查看实际图片和完整影片。

导入自己的模型时，先在素材库检查并选择模型。放入场景的草稿默认保留所有已有对象；若默认立方体或其他对象会遮挡模型，可明确选择隐藏该对象，也可勾选将新模型设为创作主体。保存会产生新版本，原版本仍可恢复。接着为导入模型选择完整取景，确认预览和交付画幅一致，再制作运动；黑画面或主体被挡住仍需查看画面排查，几何取景检查不判断遮挡。

1. 选择一个已保存、没有自身动画的静态相机。已有动画或直接跟踪对象的相机会在列表中标明，不能用于生成预览；可先用「完整取景」生成静态机位。刚保存完整取景时，如果运动草稿尚未修改，工作台会带入新机位及已选择的可见部件；已修改的运动草稿会保留，需要自行重新选择。静态机位仍需看图确认构图，相机方向无法计算时系统也会拒绝创建。
2. 展开「检查哪些产品部件」，选择整件可见产品。支持的台灯可用「选择完整台灯」；也可选择「标记为产品的可见部件」后逐项核对。标签不保证完整，未选或隐藏的部件不参与入镜核验；不要把背景或支承面误选为产品。最多可选 128 个实体，全部所选几何仍受统一预算约束。
3. 设置 1–10 秒、1%–20% 的推进幅度与方向。如果所需时长超出当前时间范围，确认允许延长；已有动画可能因此受到影响，需要重新检查。
4. 点击「生成运动预览」，等待低采样的完整影片并播放。若提示所选部件超出画面，可减少推进幅度、改为向后拉远，或先调整静态取景后重试；失败不会保存新版本。预览期间可以取消；在确认保存之前不会产生新工程版本。生成可能需要数分钟，耗时取决于场景、帧数和机器。
5. 从头到尾观看预览，检查产品是否完整入镜、是否被遮挡、动作节奏和可能的闪烁。系统在预览的每一帧核对选中部件的求值网格；当前版本保存时会对重新编译的工程再次逐帧检查，检查失败不会保存新版本。该检查不能发现遮挡、材质位移或闪烁，也不对艺术质量作保证。
6. 满意后点击「确认并保存运动」。系统保留原相机和原版本，另存运动相机和关键帧；如果保存结果因网络中断未确认，刷新后使用「重试并找回保存结果」。如果始终无法找回，可先检查版本记录，再选择「停止找回并重新选择」；之前的保存仍可能完成，此操作只清除本机的找回记录。
7. 在「启动交付渲染」中选择新相机、视频 MP4 和「视频 1920×1080」尺寸，再核对帧率、起止帧和渲染配置。这个尺寸只作用于本任务，不改变项目帧率；若项目是 24 fps，选择第 1–144 帧才是六秒。若项目帧率或范围不同，先确认实际时长，不要仅凭帧数判断。选择 `final` 后启动；采样受所选配置和预算约束。等待任务显示「交付已校验」，下载该任务的 MP4；通过「保存可编辑副本」保留同一版本的工程和影片。正式画质以渲染配置和实际检查为准，低采样预览不是最终影片。

如果还需要单张正式 PNG，可在同一保存版本中选择所需相机，让起始帧和结束帧相同；把「交付类型」设为「图片 PNG」，选择「正式静帧 2560×1440」和所需的渲染配置。图片任务不需要视频编码器。这个图片尺寸只作用于当前任务，引擎和采样来自所选配置，采样仍受实际预算限制；选择 `final` 时也应检查实际渲染结果和质量，尺寸本身不代表美术达标。任务完成且帧来源可核验后，在任务卡点击「下载 PNG」；主图、细节图和另一机位需分别选择并渲染。**先准备并保存所有需要的相机和运动，再从最终选定的同一版本渲染全部图片及影片**；每次再保存摄影都会创建新版本，先前版本的任务不能自动归到新版本的组合包。当前入口只显示单帧任务的 PNG，多帧任务尚不能在此逐帧挑选。

需要一次带走图片、影片与工程时，打开「版本」中的「保存可编辑副本」，选择同一保存版本、需要的影片，并勾选图片任务，再准备和下载 ZIP。只可选同版本已完成的图片任务，最多 16 张；复制过程中会核对原图及其原生工程来源。换了版本或图片选择后，应重新准备副本；此前准备好的下载不会冒充新的选择。预览图和多帧影片中的单帧目前不能作为这里的图片任务自动附带。

本工作区的未发布版本可在「需求」或「QA」中，把「评审画面」设为「指定保存机位」，再点击「使用最近最多 4 张已完成图片的机位」。逐项核对相机与帧，也可自行增加、移除或调整，共支持 1–4 组不同组合。点击「评审已保存版本」后，会按保存的项目画幅生成最大边不超过 640 像素、最多 16 采样的检查图并调用模型；QA 显示实际检查的相机、帧与设置。指定机位模式只提供反馈，自动修正仍使用明确标出的标准视图组。标准组按角色选相机，不自动匹配交付图片。检查图的模型意见不能代替正式图片检查，更不能验证整段影片的运动、遮挡或闪烁。

预览依赖本机 Blender、FFmpeg 和 ffprobe，只在当前本机工作台有效；预览过期或服务重启后，尚未保存的候选需要重新生成。一个已发布版本可通过相同候选的重试找回；如果工程被外部修改或校验失败，应先检查工程，再进行创作。

此流程已由维护者用完整台灯工程、实际浏览器和 Blender 验证，包括 23 个部件、6 秒运动预览及保存回执丢失后的恢复；另用标准纹理 GLB 夹具验证了模型放置与六秒预览。标准夹具不是用户自有素材，尚未完成独立创作者可用性测试或独立艺术评审。实际项目的完整性和画面质量仍需由创作者检查。
