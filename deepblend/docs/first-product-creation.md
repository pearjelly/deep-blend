# 首作：从台灯配方到三张图片和一段短片

本教程对应独立创作候选工作区，尚未随公开 0.23.0 发布。它使用香槟金属桌灯 2.2.0，沿同一作品修改尺寸、准备摄影与相机运动，最后下载三张图片、一段六秒短片和同版本可编辑工程。公开包可以创建、修改台灯并另存完整取景；下文的画幅准备、运动预览及直接图片／影片交付入口需要候选版本。只安装公开包时，请先完成第一张预览，不要寻找尚未发布的按钮。

先按[快速开始](quick-start.md)安装，再在[环境自检](environment-check.md)确认 Blender；需要影片时还要确认 FFmpeg、ffprobe。模型图片输入与评审要分别验证。手动创作不依赖模型评审成功；没有完成的评审不能视作质量通过。

## 1. 创建自己的第一版

点击「新作品」，选择「香槟金属桌灯」，核对配方版本为 2.2.0。先写下本次目标，例如：

> 暖色金属桌灯，完整主图、内衬与卷边细节、背面各一张；六秒缓慢拉远，产品装配固定，电线也要入镜。保留一份可以继续改稿的工程。

本例将「灯罩外径（毫米）」设为 **230**，选择自己的主金属颜色、旋压件与拉丝件粗糙度，先保留摄影曝光 **0**，再创建并生成预览。配方示例图不会随草稿变化；判断自己的选择要看创建后的实际图片和保存版本。

台灯默认是 24 fps、1–48 帧、4:3；正式配置默认 1024×768。这不是六秒 1080p 交付。原 `hero` 相机已有运动，后续会保留它，再另存一个用于新镜头的机位。

如果创建失败，保留输入并按[创建恢复](creation-recovery.md)重试同一次请求。回执丢失时先刷新查看保存结果，不必另建作品。

## 2. 在同一作品改稿

进入「调整」中的台灯尺寸控制，把灯罩外径从 **230** 改为 **220 mm**，保存并预览。该参数联动灯罩与内衬，不是单独缩放一个网格；支持范围为 180–250 mm。若提示零件被单独修改而发生冲突，按具体原因恢复或处理，不要重新创建项目掩盖冲突。

保存后检查实际新图：灯罩、内衬、颈口和支臂连接是否仍符合目标。用「版本」查看之前的图片；如需恢复旧版本，先确认当前没有要保留的未保存草稿。恢复后仍可继续在同一作品修改。

需要只改一处表面时，在对象编辑中选择明确部件，使用「仅当前目标（复制材质）」，先保存、再用同一机位和帧比较。不要同时改变材质与灯光后把所有差异归因于材质。具体操作见[对象编辑](modeling.md)和[固定视角检查](inspection.md)。

## 3. 先保存所有摄影，再制作运动

在「导出」中准备并保存 **16:9** 画幅。改变画幅后重新取景；旧 4:3 图片不能证明新画幅合适。

回「调整」→「摄影：相机与灯光」→「完整取景」，沿用 `hero` 在第 **24** 帧的方向，选择完整台灯，核对包含全部 **23 个可见部件及电线**，排除地面，保留每边 3% 留白。保存后查看对应新版本的图片，记下新增静态机位。它保留原相机与动画，不替换原作品。

再以 `reverse` 为方向另存完整背面机位。细节图可选 `detail`，它用于表现内衬与卷边，可以有意裁切产品；亲自检查需要的细节是否清楚。不要仅凭相机名称推断它已构图合格。

进入「导出」中的「制作相机推进」，选择刚保存的完整主机位和整件台灯，设置 **6 秒、向后拉远、8%**；允许将范围延长到第 144 帧。生成低成本运动预览，从头到尾播放，检查真实运动、出画、遮挡、接触关系和闪烁，再确认保存。系统逐帧几何检查不能代替看影片。详细限制与回执恢复见[相机运动](first-camera-motion.md)。

到这里再确定交付版本。后续重新保存摄影或改材质都会产生新版本；先前图片不会自动变成新版本的任务。

## 4. 从同一个版本渲染三张正式图片

在「导出」→「启动交付渲染」选择刚确认的保存版本，逐次设置：

| 图片 | 相机 | 帧与规格 |
| --- | --- | --- |
| 主图 | 新保存的运动主机位 | 第 72–72 帧、图片 PNG、正式静帧 2560×1440、`final` |
| 细节图 | 已检查的 `detail` | 同上 |
| 背面图 | 新保存的完整背面机位 | 同上 |

任务卡会显示实际相机与版本，完成后逐张「下载 PNG」。确认图片里的产品、材质、灯光和构图符合目标；高像素数与 `final` 名称不代表美术合格。此配方正式配置为 128 samples，实际引擎、采样和预算以任务记录为准。

## 5. 交付真实短片与可编辑工程

保持同一保存版本，选择运动主机位、视频 MP4、视频 1920×1080、`final` 和第 **1–144** 帧。核对项目为 **24 fps**，这才对应六秒。启动后等待「交付已校验」，下载该任务的 MP4，再完整观看正式影片；预览可用不代表正式影片已验收。

打开「版本」→「保存可编辑副本」，选择同一版本，附带已完成的三张图片任务和影片，准备并下载 ZIP。解压后先检查图片和影片，再用 Blender 打开包内 `.blend`。记录用户实际认可的版本；继续改稿时保留这份交付，另存新版本。

归档 README 记录了交付任务的相机和设置。工程默认活动相机或分辨率可能不同；重渲染时按对应任务选择，不要把刚打开时的默认画面当成原交付机位。ZIP 是可编辑快照，不是完整历史库或项目导入包。恢复与续交付见[故障恢复](recovery.md)。

## 6. 使用质量反馈

候选工作区可在「需求」或「QA」选择「指定保存机位」，用最近完成图片带入对应相机与帧，再主动评审。QA 显示实际检查的输入；它另渲染低采样预览，只给反馈，不自动修改装配。单部件的居中或遮挡告警需要结合整件产品和细节图用途解释；模型意见不能代替三张高清图和完整影片的检查。

后续作品可复用已保存的摄影。候选的[产品边界适配](photography-editor.md#候选按产品边界适配)允许静态模型尺寸、位置改变后，按明确选择的产品边界调整灯光和机位。请先核对完整部件、排除布景，保存预览后再检查取景；它不迁移产品动画，也不保证不同形状得到相同视觉效果。该增量尚未在真实用户自有模型上验收。

本流程的创建、尺寸续改、完整取景、运动预览、恢复、三图、六秒正式影片与归档重开均已有维护者／脚本辅助实测；并未完成一次非维护者无辅助走查或独立美术验收。已知杯柄接缝问题尚未完成质量放行，[青釉杯教程](creator-tutorial.md)保留为几何和固定视角练习，不作为推荐首作。
