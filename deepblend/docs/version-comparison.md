# 对比保存版本，继续修改

在工作台「版本」页，点击一个历史版本的「与当前版对比」。界面直接打开版本对比：左侧是选中的保存版本，右侧是当前作品的保存版本。两侧版本号、图片来源和实际渲染设置都可查看。

当前版本的「与另一版对比」会选择相邻的另一保存版本；只有一版时入口不可用。保存一次实际修改得到另一版后再查看。恢复到早期版本后，后续保存版本仍保留，也可以与真正的当前版本对照。

查看对照不会创建版本、恢复作品或自动渲染；未提交的材质、位置等修改仍保留，但不属于已经保存的版本图像。需要得到新图时，明确保存并渲染对应输入。某一版没有预览时会显示缺少图片，不借用另一版的图。

## 判断图像变化

先核对两侧版本号，再看记录中的相机、帧、尺寸、采样和曝光。不同条件会明确提示；不把不同分辨率或机位的画面直接当作材质改善。默认版本对比查看各版已有结果；编辑后自动给出的匹配条件对照继续保留其原有入口。

「看结构差异」读取当前这一对保存版本的变化。切换项目、当前指针、查看模式或配对时清理旧结果；迟到的成功或错误不覆盖后来的查看。回执指向另一作品或另一对版本时会被拒绝。

「恢复」是单独的明确操作，会切换当前作品指针，保留保存版本与原图片。恢复后再次从版本入口查看，以恢复后的当前版本为右侧。保留的未提交修改仍需核对其保存基点，不能覆盖他人后来保存的版本。
