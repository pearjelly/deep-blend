客户端源摘要、实际加载的整个浏览器应用脚本与 HTTP 响应逐字节核对。此轮只读取已保存来源和修改浏览器草稿，没有点击保存或渲染，没有模型请求。隔离副本的 30 份 Host 文件在操作前后字节一致。

[来源清单](manifest.json)与[界面记录](capture-report.json)绑定当前客户端摘要。原始 JPEG、DOM 读回、动作记录和完整脚本来源保存在 `.tmp-uv-lighttable-docs-v1`。JPEG 以原尺寸和 RGB 模式转为 PNG；重新解码后每个像素相同，未裁剪、缩放、调色或加字。PNG 中嵌入拍摄来源说明，嵌入前后像素不变。

清单中的 `nativeRegression` 保留先前 36 项真实摄影回归的原始来源、报告和请求摘要。本次界面复拍没有重跑那项原生回归，也没有把旧报告摘要更新成新来源。全部图片由 DeepBlend contributors 制作，按仓库 MIT 许可发布。
