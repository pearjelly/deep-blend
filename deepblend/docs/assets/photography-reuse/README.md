# 复用已保存摄影设置的界面截图

`draft.png`（1440×1013）与 `narrow.png`（390×844）于 2026-11-11 在隔离 DSH 中通过仓库 CDP 浏览器驱动复拍，已逐张查看。截图展示在“调整 → 摄影与灯光”中，从 `photography-other:r0003` 读取 `hero` 相机与灯光，套用到 `photography-cup:r0002` 的浏览器草稿。杯子图是先前对目标保存版本生成的真实预览，不是套用草稿后的画面；草稿尚未保存。

客户端源摘要与浏览器实际加载的完整脚本和 HTTP 响应逐字节核对。截图开始前，为目标版本生成了预览；截图过程中没有保存或渲染，也没有模型请求，133 份项目文件摘要保持不变。完整记录在[来源清单](manifest.json)和[界面记录](capture-report.json)。

原始 CDP JPEG 以原尺寸和 RGB 模式转为 PNG，重新解码后每个像素相同；没有裁剪、缩放或调色，PNG 另嵌入来源说明。清单中的 `nativeRegression` 保留先前 36 项真实摄影回归的原始来源和报告；本次界面复拍没有替换该历史来源，也不作为独立用户或美术验收。图片由 DeepBlend contributors 制作，按仓库 MIT 许可发布。
