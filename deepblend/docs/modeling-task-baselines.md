# 厚壁杯与曲面台灯的后续任务基线

这些是接续配方上下文改进的任务定义，不是已完成的真实模型验收。先完成 0.6.4 标准发布，再运行本页任务。优先 bai / deepseek-v4.1-flash；保留首选模型失败，必要时再用已配置的官方 DeepSeek-Flash。所有测试使用隔离配置，不修改个人 DSH 部署。

## 为什么先测这两类任务

当前带把手杯已有毫米单位的实体编辑界面，但杯配方 3.0.0 的创建参数仍是颜色、粗糙度和曝光。台灯配方 2.0.0 有 24 个实体，包含灯罩、内衬、支架、关节、弯臂、灯泡、旋钮和电线；创建参数也是外观与曝光。它们不能因为默认配方能渲染，就被视为已支持少量尺寸控制或任意自然语言建模。

## 固定任务

| 任务 | 提交给真实模型的一句描述 | 要重开实际文件检查的结果 |
| --- | --- | --- |
| 厚壁杯创建 | 做一个深青色陶瓷带把手杯，杯身高115毫米、杯口外径84毫米、壁厚4毫米，保存可继续编辑的Blender文件，并生成一张能看清杯口和把手连接的预览。 | 杯身实际高度、外径、壁厚和底厚；闭合连通网格、正体积、把手连接和真实预览 |
| 厚壁杯继续修改 | 把刚才的杯身改成125毫米高，壁厚保持4毫米，杯口和釉色不变；保留原版，保存新版本并重新预览。 | 新版高度、原半径/壁厚/材质保持；原场景、原生文件和预览字节不变 |
| 曲面台灯创建 | 做一盏香槟金曲面金属台灯，保留内衬、关节、旋钮和织物电线，保存可编辑Blender文件，提供能检查曲面和装配的预览。 | 实际部件、曲面、连接及原生保存；仅按作者配方能力记录 |
| 台灯灯罩联动修改 | 把这盏台灯的灯罩外径改为230毫米，保持金属厚度、内衬间隙和颈部连接，弯臂、灯泡和关节要保持装配正确；保留原版，保存新版并重新预览。 | 实际外径、壁厚、内衬和颈部间隙、弯臂端点、灯泡与关节连接；不能用整体缩放代替装配验证 |

先记录当前行为与拒绝结果，再决定具体实现。台灯任务可能揭示现有尺寸入口的缺口；维护者手写场景修正不能替代模型自行完成。

## 每轮保留什么

记录用户提交、澄清和点击次数，模型步骤、工具调用、实际耗时、返工与输入/缓存/输出 token。等到本轮模型回复结束，并同时拿到要求的原生文件和实际预览；看到中间 manifest 不能提前终止，最终回复超时仍记失败。

独立重开 `.blend` 检查实际几何，不以 SceneSpec 数字替代测量。杯口直径不能直接拿含把手的整个对象包围盒代替。台灯要测不同部件的连接和间隙，记录应改变与应保持的部件。旧版本保护用实际文件哈希核对。

固定相机、帧、CPU、随机种子、采样和分辨率，保留整体、杯内/把手、灯罩/弯臂等细节图。前后比较使用同任务、模式和模型；固定图片说明形体变化，一组模型观测不代表总体速度或成功率。技术通过、成品观感、真实模型任务和外部采用分别记录。当前模型的图像输入与审阅路由仍待实测，不能补写艺术认可或外部使用记录。
