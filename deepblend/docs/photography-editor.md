## 使用方式

在场景页的“摄影：相机与灯光”中选择已有相机，修改焦距、位置及瞄准对象原点或指定坐标。相机可选择自由旋转、对象原点或坐标目标。切回自由旋转会明确清除旧瞄准目标；使用目标时，旋转输入由目标控制。相机动画驱动的位置和旋转轴锁定，旋转动画存在时也锁定瞄准设置。

选择已有灯光可改位置、旋转、能量、RGB 和尺寸。原有类型只读；“新增面积补光灯”会创建独立 ID 的面积灯草稿。面积灯尺寸显示方形边长，点光与聚光显示柔光半径，太阳光单独显示强度且没有无效尺寸输入。完整定义保留原有 scale、sensorWidth、clipping、fStop、spotSize、spotBlend 和 angle 等未改字段。

这里选择的是编辑和检查用相机；项目的活动相机和最终交付机位不会随此选择改变。 检查图按原尺寸显示，空间不足时缩小；小尺寸图片不会自动拉伸到面板宽度。

选择相机、帧与采样数后，点击“保存并预览”。保存请求复用 ScenePatch，固定草稿的 projectId/baseRevision，并设置 saveCheckpoint:true、renderPreview:false。保存回执的 revision 和 digest 决定随后材质检查图的来源；相机、帧和采样数来自点击时的草稿。客户端立即刷新当前场景，但不会用刷新结果替换这次图片请求的来源。

图片失败或取消时显示“修订已保存”，保留该次保存记录。“重试已保存修订的预览”只重试图片，即使当前修订后来改变，也仍读取原来保存的修订。“恢复摄影编辑前的场景”恢复整个场景，以编辑后的 revision 作为 expectedCurrentRevision；并发变化时拒绝覆盖，保留编辑记录和现有草稿。

轮询不会覆盖有改动的草稿。切换项目后可回到该项目继续编辑；草稿来源与当前修订不同则禁止保存，可显式放弃草稿并重新读取当前值。已保存字段由 Host 场景重新读取；未保存草稿和本次保存/恢复记录只在当前页面会话保留。

这里的瞄准对象是根原点，不是包围盒中心，也不是运动跟踪约束。不提供未保存草稿试渲染、自动取景或曝光/环境编辑。旧 Host 仍可使用原有摄影编辑；复用与清除目标需要更新插件并重启 DSH。

## 完整取景

移动模型后，原相机可能只拍到背景。在「调整 → 摄影与灯光 → 完整取景」中，选择沿用取景方向的相机和明确取景帧，然后点击「保存完整取景」。整盏台灯默认选择全部 23 个部件，包含灯泡和电线，不含地面或外部支承。可展开「选择部件与留白」调整选择，或点击「选择整盏灯」恢复整件选择。留白默认每侧 3%。

保存会测量真实 Blender 几何，沿用来源相机在该帧的方向、滚转和光学设置，新增一个静态机位。独立核验全部选中几何在画幅与裁剪范围内后，才保存新版本并显示实际预览。原相机、动画和镜头安排保留；最终交付机位不会自动切换。

请先保存或放弃其他草稿。版本变化时，点击「重新读取当前版本」再调整。保存结果尚未确认时，输入会锁定；「重试同一次保存」沿用同一部件选择、版本和机位，不会重复创建相机。刷新页面后回到「调整 → 摄影与灯光」可继续这次重试。浏览器必须允许本站保存重试信息，才能发送请求。取消会中止当前操作；连接中断后仍需读取或重试来确认最终状态。

核验只针对明确帧和当前预览画幅的完整几何边界。请看预览检查遮挡与美术效果；更换交付画幅后需重新检查。它不核验透明材质、着色器位移或整个动画范围。不支持的隐藏部件、模拟或过重几何会明确拒绝。

## 复用已保存摄影设置

在摄影面板选择“来源作品”和“来源保存版本”，再选择来源相机。读取的是明确的保存版本，不会随着来源作品当前指针改变。面板显示来源作品、版本、摘要和灯光数；网络读取失败可重新读取，错误身份或迟到的旧选择不能替换后来选择。

“套用到摄影草稿”会替换目标作品的全部灯光，以及当前所选相机的焦距、位置、朝向或瞄准设置。目标相机的 ID、用途、传感器、光圈、裁剪范围与缩放保留；其他相机、模型、材质、世界、动画、镜头安排和交付设置保持。若已有未提交摄影修改，须先勾选明确替换摄影草稿；其他未提交编辑保持。

来源相机瞄准对象时，必须在目标作品中明确选择瞄准对象，不能沿用另一作品的对象 ID。动画锁定仍有效，存在冲突时拒绝套用，保留原草稿。来源灯光保留完整定义，包括原类型、光色、尺寸、位置与旋转，以及聚光和太阳参数。

默认按原坐标以米直接复用。两件尺寸或位置不同的作品可能需要继续调整位置、灯光和瞄准点。保存版本记录复用来源作品、版本、摘要和相机；保存前仍可继续调整草稿。套用后检查参数，明确“保存并预览”才会生成版本与检查图。读取与套用不会保存场景；保存后仍可重试原保存版本的图片或按现有条件恢复整个旧场景。

### 候选：按产品边界适配

当前未发布工作区增加了可选的边界适配；公开 0.23.0 和较早本地候选不含此增量。它适合静态产品的尺寸、位置改变后复用一套已保存的摄影设置。在“复用方式”选择边界适配，指定来源相机与来源帧，分别展开来源、目标产品部件，核对整件产品。选中完整导入实例时会读取其全部子网格。地面、支承和布景应排除；默认部件只是起点，仍需核对。

点击“套用到摄影草稿”后，Host 读取两个保存工程的真实边界，以边界对角线之比统一缩放机位与灯光相对产品中心的位置。复制来源相机在明确帧的焦距与朝向，目标传感器、偏移、光圈和裁剪范围保留；启用景深时重新计算目标对焦距离。非太阳灯的尺寸随比例变化，功率随比例平方变化；太阳强度和角度保持。模型、材质、环境、其他机位、动画和输出设置保持。

这是一项摄影起点，不保证不同形状、长宽比、材质和环境得到相同构图或亮度。先检查草稿，再保存预览；必要时使用完整取景。规划期间可以取消；失败、版本变化或迟到回执会保留原草稿，不会偷偷改用原坐标。保存记录包含原始版本、工程摘要、所选部件摘要、帧和适配比例。

每侧最多选择 128 个实体或完整实例，合计最多 128 个网格、两百万顶点或多边形；最多 32 盏已命名灯光。产品及其几何依赖、目标机位和灯光须静态。来源机位可有动画，但只采样明确帧，不迁移整段运动。隐藏成员、未管理的活动光源、自定义灯光节点、模拟或不同的视口／渲染几何会拒绝。静态 Boolean 工具可以作为几何依赖读取，不应被误选为产品。旧 Host 不支持此方式时会提示升级，仍可明确选择原坐标复用。

2026-11-01 的真实浏览器、Host 和 Blender 专项使用静态台灯夹具：目标整体放大两倍并平移，原坐标预览只显示背景，边界适配后重新完整入画并保存。13 项浏览器流程检查通过，独立重开工程对全部 23 个部件的 51,786 个顶点投影、几何、UV、法线、材质和其它机位核对通过。14 个原生对照覆盖 128 成员、静态 Boolean、动画来源机位，以及隐藏、动画依赖、额外光源和超量网格等拒绝分支。证据在 `.deepblend/quality/photography-bounds-ui-disclosure-20261101/` 和 `.deepblend/quality/camera-fit-photography-20261101/`。640×360、16 samples 图片仅作功能检查；这不是用户自有模型、非维护者试用或美术放行。

### 历史：最初摄影编辑专项

最初的实际 Chrome/Host/Blender 专项通过 23 项：

- 真实表单修改杯体相机焦距、位置、目标点及灯光能量/尺寸，新增面积灯并生成图片；项目切换和轮询保留各自草稿及输入焦点。

- 同一 CPU、单线程、种子及摄影条件下重复基线像素相同；仅修改灯光后像素变化。取景修改后杯体仍在相机范围内；取景与新增灯同时发生的图片不作为单因素对比。
- 条件恢复、刷新读回、旧文件原字节保护及窄屏输入的水平范围已检查。已查看三张页面截图与实际前后图片；窄屏截图只覆盖相机区，未声称完整移动操作流程通过。
