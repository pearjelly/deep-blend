# 0.21.0 候选：一次摆放完整台灯，再继续修改

本版本尚未发布。当前稳定版是已完成 GitHub、npm 和社区公开目录读回的 [0.20.0](0.20.0.md)。

这轮把完整台灯的移动、绕指定竖轴转向，以及落到实际支承表面合并成一次保存。工具沿用 `blender_place_on_surface`，显式选择整灯范围；工作台在「调整」提供支承、世界位移、转向和竖直间隙。Host 从保存的 2.2.0 配方锁解析全部 23 件，包括电线、灯泡和毛毡脚，用户不用手写成员变换。

保存前按完整原生网格求接触，候选编译后重新打开基线与候选，核验每件都遵循同一个刚性世界变换，且局部几何、UV、材质和支承保持。漏动任何一件均拒绝整次保存。摄影设置保持；大幅移动后仍须检查构图。摆放后继续通过原尺寸入口修改灯罩直径。

已完成 0.20 手工基线、原生专项 34 项和真实浏览器专项 28 项检查。浏览器涵盖一次整灯摆放、250→230 mm 两次续改、重载、原生独立检查、历史保护，以及桌面/手机两种预览模式的保存提示。界面复核指出的提示隐藏问题已由同一复核员复判为解决；这项复判只覆盖该问题。

首轮单元整轮为 143/149：包含隔离预设/SDK 工具链未准备、文档新鲜克隆读数、工具参数读取扫描、翻译调用扫描，以及当前截图来源绑定的问题。原日志保留；随后补齐隔离环境、明确参数/翻译调用，并从当前客户端重新拍摄文档截图，相关复验通过。断言计数已实测为 2130 项自计断言与 2066 个 `node:test` 用例；不能把计数通过当成全部测试通过。

冻结来源的连续 46 套完整验收、真实模型同任务对照、确切提交 CI、最终主线构建、全新安装与 GitHub/npm/社区发布均仍待执行或验收。参数范围、失败记录、耗时口径及独立证据边界见[整灯摆放说明](../lamp-assembly-placement.md)。

首次冻结完整验收的单元层为 148/149，检出默认单件请求多带了 `scope:undefined` 与 `pose:undefined`。确认失败后停止该轮，运行前后全部 983 个跟踪文件保持。随后改为只在调用方提供值时添加新字段，并在原有测试中同时核对默认请求形状、整灯位姿转发及旧 Host 的整灯拒绝。原失败与对应 CI 保留；修正来源另行冻结和完整运行。
