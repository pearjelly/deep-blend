# DeepBlend Studio 0.3.1

**Create. Refine. Render. — Your Blender studio, inside DSH.**

A packaging and onboarding update to the product-scene workflow introduced in 0.3.0.
The scene tools and runtime behavior are unchanged.

## What changed / 本次更新

- A consistent orange cube identity, repository banner and social preview artwork.
- Reorganized English and Chinese homepages: install first, see real renders, follow a cup walkthrough.
- A bilingual [quick start](../quick-start.md) and [documentation index](../README.md).
- Matching npm, market and release introductions, with branding assets included in the bundle.
- A feature request form and updated discovery metadata.
- Reproducible brand sources and provenance, distinct from actual Blender renders and workbench screenshots.

## Install / 安装

```sh
dsh plugin --profile web add @deepblend/dsh-blender-bundle
```

Or use the prebuilt bundle:

```sh
dsh plugin --profile web add https://github.com/pearjelly/deep-blend/releases/latest/download/deepblend-bundle.tgz
```

Restart `dsh web`, choose **DeepBlend Studio** in a new session, then open Blender in the sidebar.
Node.js **22.23.3+**, DSH **0.1.5-rc.2** and Blender **5.2.1** are required; MP4 delivery needs FFmpeg/ffprobe.
See the quick start for first-time setup and other platforms.

## First creation / 第一次创作

Follow the [glazed cup walkthrough](../creator-tutorial.md): change height, compare clay views, refine
glaze and lighting, then deliver a frame. It shows original outputs and the remaining handle-root bulges.
A static recipe does not become a turntable by adding frames.
