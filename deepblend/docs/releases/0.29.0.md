# 0.29.0 候选 · 一次预览并保存两组木条的纹理方向

在工作台的对象编辑器选中半搭接的一组木条，开启逐面 UV 投影，并勾选界面列出的另一组木条。一次设置旋转和重复次数即可应用到两组。可先从已保存的相机预览，再把修改保存为一个新版本。

这项操作适用于同一个已保存半搭接的两组木条。旧的胡桃木格栅垫 1.1.0 配方可按原锁继续编辑。新修订记录两组 UV，原修订仍可打开。取消预览时不会产生新修订，草稿修改或项目切换会使之前的预览失效。[逐面 UV 指南](../mesh-uv-projection.md)

维护者在 Chrome 和 Blender 中以同一个 64 mm 格栅垫项目条件比较了逐组设置与配对设置。以字段修改为一次操作，进入对象编辑器后从八次减少到五次，其中保存从两次减少到一次。两次运行的最终场景与固定机位像素一致。该计数未包含可选的保存前预览。[浏览器对照](../validation/timber-uv-browser-actions-1127.json)
