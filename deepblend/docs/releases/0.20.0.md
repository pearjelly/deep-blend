# 0.20.0 候选：已摆放台灯继续改尺寸

本版本尚未发布。新增能力是：台灯 2.2.0 的完整 23 件静态装配经过整体世界 XYZ 平移和竖轴旋转后，仍可通过原参数入口将灯罩改为 250 mm，再回到 230 mm。每次保存新的可编辑版本，保留已有摆放、材质、相机和未受控的细分、倒角等编辑。180–250 mm 的尺寸范围及超过 230 mm 时支架和弯臂的联动均为已有功能。

参数更新核验原始配方锁与全部成员，包含未绑定尺寸的灯泡；八个支架沿台灯方向移动，弯臂只修改自身局部路径。整灯倾斜、缩放、缺件、单件错位、受控轮廓或路径改造，以及产品成员的变换动画、骨架和物理状态均提示冲突。地面和无关场景物体不参与装配识别；无关物体的动画或物理状态不阻止静态台灯续改。此范围不扩展到未知来源、任意装配或烘焙变换。

当前专项为参数契约与 Host 100/100、独立原生 297/297、真实 UI 30/30；三项产品变异均被指定断言捕获，原生七个错误对照与一个无关物体允许对照全部通过。四种原生摆放的十二次尺寸检查均保持固定相机与历史文件，最大局部顶点误差为 0.000053727 mm，低于修改尺寸前冻结的 0.000429815 mm 容差及 0.01 mm 硬上限。

首次原生面顺序误报，以及 UI 对象键顺序误报、图片区选择错误的失败均保留；修正仅涉及测试，之后各自重新完整执行。详细范围见[台灯摆放记录](../lamp-placement.md)。这些结果不证明全表面最小壁厚、任意场景观感或模型自主任务成功。

候选另已完成同一次完整契约回归：146/146 文件正常通过，用例快照见主 README。冻结提交的 44 套完整原生回归、确切提交 CI、真实模型/自然语言验收、构建安装以及 GitHub/npm 和安装路线公开读回仍待完成，不能据专项结果宣称 0.20.0 已发布。
