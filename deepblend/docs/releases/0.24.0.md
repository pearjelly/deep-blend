# 0.24.0：独立创作、英文指南与安装修复

0.24.0 于北京时间 2026 年 11 月 11 日 16:51:37 公开，发布包从主线提交 `b3ce642f` 构建。[GitHub Release](https://github.com/pearjelly/deep-blend/releases/tag/v0.24.0)

独立产品创作增加环境和图片输入检查、相机运动预览、指定机位评审、图片与影片交付，以及可选的摄影边界适配。可编辑副本可以附带同版本的已完成影片和最多 16 个单帧任务。画幅变化后可重新检查取景。操作流程见[完整首作教程](../first-product-creation.md)。

非中文用户现在可以从英文 README 进入创建、建模、摄影、恢复和工具契约五篇指南，完成从配方到保存版本、比较、可编辑副本和交付的现有工作流。每篇均可返回中文原文；中文的历史实验与图片记录继续保留。贡献指南提供统一术语和两种语言一起维护的约定。

DeepBlend Studio 与开发预设的列表说明均可用英文阅读，开发预设显示名称同时包含英文与中文。工作台已有的中英界面继续跟随 DSH 语言设置，本轮没有重复实现。

源码安装/卸载事务修复了本机 Node 24.13.0 对目录符号链接删除报错的问题：删除文件或链接时使用 unlink，保留目标包目录和内容，继续执行既有并发保护与回滚。这一安装修复本身不改变 Blender 建模、渲染和 UI 实现。

详细范围、故障与验证边界见[英文工作流记录](../english-workflows.md)。
