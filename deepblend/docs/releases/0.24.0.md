# 0.24.0：英文核心指南与双语预设入口

非中文用户现在可以从英文 README 进入创建、建模、摄影、恢复和工具契约五篇指南，完成从配方到保存版本、比较、可编辑副本和交付的现有工作流。每篇均可返回中文原文；中文的历史实验与图片记录继续保留。贡献指南提供统一术语和两种语言一起维护的约定。

DeepBlend Studio 与开发预设的列表说明均可用英文阅读，开发预设显示名称同时包含英文与中文。工作台已有的中英界面继续跟随 DSH 语言设置，本轮没有重复实现。

源码安装/卸载事务修复了本机 Node 24.13.0 对目录符号链接删除报错的问题：删除文件或链接时使用 unlink，保留目标包目录和内容，继续执行既有并发保护与回滚。此修复不改变 Blender 建模、渲染和 UI 实现。

详细范围、故障与验证边界见[英文工作流记录](../english-workflows.md)。后续公开发布与安装状态以对应发布记录为准。
