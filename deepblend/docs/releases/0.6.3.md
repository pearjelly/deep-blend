# 0.6.3 候选：修整音箱编织格栅

状态：候选，尚未正式发布。公开稳定版本仍为 0.6.2。

音箱配方升级为 2.1.0，平滑两组经线的折弯。用户继续通过三个毫米尺寸参数修改 111 个实体组成的装配，保留线径、格栅裁切、材料与按钮动画。新建作品使用修整后的模型；旧版已保存作品继续保留原几何并可修改尺寸。

默认和最大箱体尺寸的实际 Blender 网格均通过格栅表面交叉与封闭检查。固定条件前后图保留整体外观，近景经线弯折更平滑。网格成本约增加到原来的 2.42 倍，具体测量及边界见[质量记录](../speaker-weave-quality.md)。

专项检查 68/68；两项恢复折线或降低分辨率的变异被拒绝。冻结提交的完整验收、确切提交 CI、干净提交构建、GitHub Release、七个 npm 包公开读回、三路安装和社区更新仍需完成。不能把本候选当作已发布版本或任意自然语言建模成功。
