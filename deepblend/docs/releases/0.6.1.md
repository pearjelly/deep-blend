# 0.6.1 候选：自包含安装组件归属

加固自包含安装的组件归属，并检测 DSH 安装目录导致的旧工作区覆盖。运行器、Host、
预设和工具入口通过 bundle 的导出路径加载自身依赖；工作台在 bundle
根入口挂载，以便 DSH 同时发现属于它的浏览器组件。浏览器实现仍以 UI
包为规范源，生成副本只修改注册身份，契约和 CI 检查两者一致。

已有音箱的三参数保存、版本恢复、外观和摄影设置保留继续沿用 0.6.0 能力。
源工作台已通过实际浏览器/Blender 112 项检查；最终发布需要干净源码的
完整检查、实际打包安装组件来源核验及公开三路安装。当前是候选版本。

DSH 的 bundle 配置层优先从其安装位置解析；若 DSH 部署嵌在旧 DeepBlend
工作区中，必须改用工作区之外的 DSH 部署。插件不能更改 Harness 的这项
解析规则。发布探针读取实际选中的 bundle 路径，发现覆盖就判定失败，
不会只凭 profile 中的版本号声称新安装已生效。
