# DeepBlend 0.6.1 — 安装归属可核对

DeepBlend 0.6.1 加固安装一致性：完整插件通过自己的入口加载运行器、Host、预设和模型工具；工作台加载属于当前安装的客户端。单独挂载 UI 组件仍可打开全屏工作台。

安装验证现在会核对 DSH 实际选择的 bundle 配置路径。若 DSH 部署位于另一个旧 DeepBlend 工作区内，Harness 的安装优先规则可能覆盖刚安装的 profile 包；检查会明确指出这一情况。请使用独立于其它 DeepBlend 工作区的 DSH 部署。

已有音箱继续使用三个毫米尺寸输入调整 多部件音箱场景（111 个实体，含辅助工具和布景），保留独立外观、摄影和历史。参数保存、版本恢复、PNG 原图与 MP4 交付保持原有操作方式。

发布校验直接读取归档的受检文件，减少约 150 MB 的额外展开空间。仍校验四个目标平台的包版本、许可、二进制头和完整字节；不代表已经在所有平台执行。对应 49 项检查包括临时目录不可创建、符号链接、缺失文件和字节变化。

验证范围：冻结产品来源 d25fa15 的整轮本地运行为 33/39，六项在磁盘耗尽期间失败；在不改源码的情况下逐项复验后，创建恢复29、摄影36、尺寸创建11、已有装配24、预览历史71、固定视角23均通过。39 套流程分别有通过证据，未把原失败运行写成一次整轮通过。676 个源文件前后不变。之后 d2e1354 只修改发布校验工具和测试，七个产品包字节相同。
