# 0.10.0 候选：保存模型的局部壁面与内衬测量

在已保存的 Blender 模型上选少量部件和局部射线，可检查真实网格壁面弦长及壳体退出面
到指定内衬入面的距离，保留来源修订、原生文件摘要、帧与命中点。未命中、重叠、遮挡
及不支持的网格明确不可测；测量不创建修订，不覆盖旧文件或手工改动。

同一个场景工具提供紧凑测量回执，省去无关场景目录；普通读取与原生跨度v1保持兼容。
比较两份保存修订时，由工具核对两份来源并计算逐样本差值及所有可比样本的最大变化；
只可测壁面的样本仍计入壁面变化，不适用结果不能被当成零。
毫米差值及百分比都由工具计算，壁面和内衬间距分别给最大变化，避免模型混用上限。
局部采样不代表全表面最小壁厚、整机净间隙、无碰撞、无自交、制造认证或艺术认可。
