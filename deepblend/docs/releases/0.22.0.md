# 0.22.0 候选：另存完整取景，保留原相机与动画

本版本尚未发布。当前 GitHub/npm 稳定版为 [0.21.0](0.21.0.md)，社区两份公开目录的版本刷新单独记录。

移动或改完产品后，可以在工作台点击「保存完整取景」，或让 DeepBlend Studio 调用 `blender_camera_fit`。功能按明确帧与完整所选网格保存一个新的静态机位，沿用源相机求值后的方向与光学设置，保留原模型、材质、灯光、相机、动画和镜头安排。支持完整导入实例；受支持的台灯默认选择包括灯泡与电线的全部 23 件。候选编译后的原生边距与裁剪复验通过才发布，失去回执后重试和刷新沿用同一请求。

专项原生 22 项与真实浏览器 18 项已通过，覆盖横竖画幅、传感器模式、镜头偏移、滚转、导入层级、拒绝与真实损坏候选、响应丢失及重载。冻结来源 `c4f17bf` 完整单元与契约 154/154 文件通过，995 个受控源码文件字节与模式保持；同一日志实测 2131 项自计断言和 2137 个 Node 用例。之前 147/154 的失败记录保留，环境、文档与参数读取问题未被写成通过。

相同中文任务、完整输入图和 r0003 台灯的单次正式 DSH 对照中，候选以 7 次模型请求、8 次工具调用完成；独立重开保存文件，16 项检查通过，23 件的 51,786 个顶点满足 3% 边距与裁剪要求，原相机 1–48 帧结果保持，PNG 与可编辑文件均成功登记。旧版也保存并展示完整台灯，但源方向与裁剪保持检查失败，12 次请求、18 次调用达到预算而未正常结束。没有重试；不比较耗时、不推断成功率、美术质量或外部采用。原回复中的对焦与角度描述错误另记，不改写原文。

连续 48 套完整原生验收、对应提交 CI、最终主线构建、干净安装与 GitHub/npm/社区发布仍待执行。操作、完整原图、边界和来源摘要见[完整取景指南](../complete-view.md)与[验证记录](../validation/complete-view-1026.json)。
