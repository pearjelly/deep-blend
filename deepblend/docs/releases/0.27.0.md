# 0.27.0 候选：用一个参数调整居中的格栅间距

本版本尚未发布，完整验收与确切提交 CI 待完成。

胡桃木格栅垫配方升级为 1.1.0。创建时可填写 52–92 mm 的「横条间距」，默认 78 mm；保存后的作品也能通过装配参数继续修改。三根横条的阵列偏移与对象位置同步变化，中心始终为 `[-间距, 0, +间距]`。保存生成新版本，原始工程和来源锁保留。

配方契约新增显式声明的 `recipe.array-bindings`，只允许绑定已有阵列偏移的单轴。手工修改受控偏移、阵列数量或排列后，联动编辑返回冲突。独立的材质和摄影编辑保留。1.0.0 的原始配方已保存为历史夹具，旧项目继续按原锁读取，不自动增加参数。

真实浏览器专项 23 项通过：创建 52/92/64 mm、连续保存 64→92→78→64 mm、刷新、390px 控件和可编辑 ZIP 下载。独立 Blender 重开七份工程，包括下载解压后的副本，均测得 240×240×20 mm、七个封闭实体、十二处交叉及零采样重叠。完整条件、受保护文件摘要、初次量具失败与复验见[候选验证记录](../validation/trivet-spacing-candidate-1121.json)。这些测量不代表制造适用性。
