# 0.3.7 — 比较配方，保留各自的调整

比较台灯、杯子等作品起点时，各配方保留自己的颜色、粗糙度与曝光。切换回来继续调整，再点「已选择」也不会重置。名称与目标保持，明确「恢复配方默认值」只影响当前配方。

比较设置随本浏览器的创建草稿保存，重载或重新打开后明确恢复。配方版本与内容摘要分别匹配，旧草稿仍能继续；损坏或不明确记录会被拒绝。选择、比较和恢复不创建项目或自动渲染，示例图仍展示默认值。明确创建时才渲染当前选中的输入。

成功创建后，其他未提交的配方设置和后来输入保留；原创建请求的重试输入固定。清空当前创建草稿会清理本页的比较设置，不删除项目。浏览器存储范围与容量限制沿用既有草稿规则。

详见[配方比较](../recipe-comparison.md)、[创建草稿](../creation-drafts.md)与[每日发布状态](../daily-releases.md)。候选专项不代替最终连续完整入口、实际 CI 和公开发布读回。
