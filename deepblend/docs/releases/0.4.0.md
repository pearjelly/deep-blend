# 0.4.0 — 复用已保存作品的摄影设置

从已保存作品选择版本和相机，将摄影设置套用到当前作品草稿，减少重复输入。相机的可编辑设置与整组灯光复用，目标作品的模型、材质、世界、动画、其他相机、传感器/光圈/裁剪范围和交付设置保留；仍须明确保存并预览。

来源固定到作品、版本与摘要，保存记录保留来源。对象瞄准须在目标作品中明确映射；旧读取和失败不会替换草稿。已有摄影修改需要明确选择替换，其他编辑保留。位置按原坐标以米复用，不自动缩放或取景，不同尺寸的模型仍须检查构图。

相机支持显式清除旧目标、返回自由旋转；动画约束保持。旧 Host 保留原摄影编辑，更新并重启后才能使用新增能力。

已完成 GitHub Release、七个 npm 包、匿名文件/完整性读回及整轮三路安装验证；现有社区投稿已更新，等待维护者审核。使用与边界见[摄影编辑](../photography-editor.md)，完整原始记录见[每日记录](../daily-releases.md)。
