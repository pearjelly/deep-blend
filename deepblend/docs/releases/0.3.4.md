# DeepBlend Studio 0.3.4

**Keep your first image with one click. / 一键保存第一张作品。**

预览上方新增「保存预览 PNG」。从配方生成第一张实图后即可保存原始图片，不需要视频编码器，也不需要再次渲染。

- Save the actual PNG shown in the latest preview, render/revision comparisons, inspection gallery and photography results.
- Keep its original pixels, dimensions and samples. The filename identifies the project, source revision, camera or mode, frame and image digest.
- Verify exact bytes against the displayed source before browser handoff. Replaced paths, incomplete metadata, truncated data and wrong dimensions fail visibly.
- Save from LAN HTTP as well as local/secure contexts. Preparing supports cancellation, a 30-second deadline and retry.
- No scene writes, new revisions, render jobs, video encoder or online model calls are required for saving.

浏览器负责最终文件位置及写盘；工作台回执表示已交给浏览器。重复保存时可能覆盖或重命名，取决于浏览器。保存保留预览质量；需要更大尺寸或更多采样时，请先生成相应渲染。
