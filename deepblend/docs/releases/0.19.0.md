# 0.19.0：按实际表面放置模型

这是表面放置版本的候选说明。最终验收、确切来源及公开渠道状态以 [GitHub Release](https://github.com/pearjelly/deep-blend/releases/tag/v0.19.0) 的发布记录和证据资产为准；本页不代替发布读回。

在已有作品中指定主体、支承和检查帧，即可用 `blender_place_on_surface` 把静态模型放到所选表面。操作保留水平位置、旋转和缩放，只改变世界 Z，保存新的可编辑版本并默认返回同一帧的预览。生成网格和含多个子网格的导入模型均走完整实际网格计算；倾斜表面与孔洞不由整体包围盒代替。

`clearanceMm` 表示竖直间距，默认零。保存前重新打开候选与原文件，确认所选主体仅发生要求的平移、支承保持，并复核实际残余间距。源文件、资产或候选文档变化，取消以及计算、编译或预览失败均不发布候选；相同请求重试返回已有结果。

该结论覆盖所选两个实体在明确帧的求值网格，不证明物理稳定、其他物体碰撞、欧氏最短距离或整段动画。相关动画、驱动、物理、跨对象几何依赖、不完整层级以及计算预算超限会明确拒绝。

同源维护者实测中，旧版通过三次 Host 调用对齐斜面的包围盒后仍有 128.825 mm 悬空；候选一次放置的独立原生读回间距为零。两者底层执行都约四秒，不能表述为渲染加速。这不是模型成功率。复杂佛像原例在保留全部网格的上界剪枝后，实际只读测量由首次 120 秒超时变为 25.942 秒完成，原工程保持。

具体算法范围、独立原生读回、提交边界修复和失败记录见[表面放置记录](../surface-placement.md)。


同一请求与起点的真实 DSH 模型对照中，旧版也自行完成放置：171.503 秒、15 次工具调用。首次候选为 97.943 秒、11 次调用，但文件卡片因相对路径登记失败；修复回执的项目目录后，新的一次完整回合为 165.206 秒、13 次调用，实际 `.blend` 和 frame 1 预览均成功登记。独立原生读回均为零竖直间距、仅主体 Z 变化。最终复验仍保留一次额外几何查询的业务错误；单例不支持普遍速度或成功率结论。
