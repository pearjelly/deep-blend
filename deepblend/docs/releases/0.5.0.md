# DeepBlend 0.5.0 — 三项尺寸创建完整桌面音箱

在图库选择音箱，填写箱体宽、深、高，即可创建含 111 个部件的可编辑 Blender 模型。只把宽度设为 300 mm，保持默认深、高，就得到 300×138×162 mm 的箱体。外壳、内腔、开口和盖板联动；格栅、旋钮和脚垫跟随装配位置，保留零件尺寸、底面高度和按钮按压行程。

支持宽 264–340、深 138–180、高 162–220 mm。无效输入会在创建前被拒绝。摄影机随尺寸和对应部件调整，最大尺寸下的旋钮仍保留在细节画面内。原版配方输入完整保留，图库升级不会改写旧项目。

作者接口增加局部三轴盒体尺寸，以及受约束的尺寸、位置、摄影机和动画位置偏移绑定。运行组件不支持新能力时，在编译前明确提示，并保护当前版本。

尺寸输入用于创建新模型。已有音箱的整套尺寸修改是下一轮重点，当前仍可编辑部件、材质和摄影设置。
