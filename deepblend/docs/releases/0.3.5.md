# DeepBlend Studio 0.3.5

**Continue after a creation failure. / 创建失败，继续原来的作品。**

创建失败后保留点击时的名称、目标与配方参数。工作台给出 Blender 修复指南、只读刷新和「重试上次创建」，避免从头填写。

- Retry the original captured request while keeping any newer draft you typed.
- Recover an already saved project if its successful response was lost, without another project, compile or render.
- Keep later saved revisions when recovering an older creation request.
- Show incomplete creations without opening their unpublished initial revision.
- Use optional `creationKey` through the host, HTTP creation route and agent tool; older hosts without the recovery capability refuse keyed creation before writing.

创建草稿与重试标识保留在当前页面；重新加载或关闭页面后的恢复尚未提供。未完成、重复或损坏的创建记录会明确拒绝恢复，需要检查存储，不会自动删除或重建。恢复适用于使用同一项目存储、遵守写入协议的本地进程。
