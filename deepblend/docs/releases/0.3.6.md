# 0.3.6 — 重载后继续创建草稿

创建时填写的名称、目标、配方参数与原重试请求保存在当前浏览器。刷新或关闭后重新打开工作台，可以选择“继续这份草稿”，再明确创建或重试；恢复本身不会创建项目。

如果原项目已经创建、成功回执却丢失，恢复后重试仍使用原请求标识与输入，继续原项目。后来输入的新草稿和其他打开页面的记录分别保留。已关闭页面的草稿成功复制到当前页面后，移除旧副本；复制失败则保留原记录。

草稿按项目存储位置隔离。旧配方的版本或内容已变化时说明原因，不悄悄套用新配方。无法保存、损坏或过大的记录会给出提示；删除和清空只作用于浏览器草稿。每个存储位置最多保存 20 份，每份上限 256 KiB。

这是当前浏览器的本地保存，不提供跨设备同步；清除浏览器存储后无法恢复。浏览器突然终止可能留下旧副本，可以明确删除。详见[创建草稿](../creation-drafts.md)和[创建恢复](../creation-recovery.md)。

最终连续完整验收、实际 CI 和公开安装读回均通过；来源与边界见[每日记录](../daily-releases.md)。
