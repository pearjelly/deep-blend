# 0.31.0 · 一次保存两组木条的贴图和 UV

在素材面板打开已检查的底色贴图，选择已保存的半搭接木条并勾选另一组。开启「同时重建两组 UV」后，设置纹理方向和重复次数，可先从已保存的机位预览，再用一次保存应用图片和两组 UV。UV 层可留空或填入 `UVMap`。

两组保留各自材质的数值和其他图片绑定。共用这一层的贴图会使用重建后的坐标，操作前可查看实际渲染。预览不产生修订，取消或修正草稿后仍可从原工程继续。

在同一份锁定 1.1.0 配方的胡桃木格栅垫上，分别执行两次保存和从素材面板一次保存。两种方法得到相同的场景内容和固定机位像素。实拍木纹样本中，两组共 496 个退化 UV 三角形降到 0。验收还覆盖共用 UV 层的粗糙度贴图，以及缺失目标时返回 422 并保留原工程。[双路径浏览器验收](../../tests/e2e/timber-uv-ui.e2e.mjs)
