## 从版本页保存可编辑副本

在运行 Host 的电脑上打开工作台，进入「版本」→「保存可编辑副本」。默认导出当前已保存的版本，也可以选一个历史版本。选择「准备下载」，完成后即可下载 ZIP。未保存的编辑不会进入这份副本。

ZIP 保留所选版本的原始 Blender 文件、场景描述，以及导出器支持并核验的外部素材，同时附有打开说明、文件校验清单和已有的素材许可声明。若该版本有符合核验条件的已完成影片，也可以一并带上；准备副本本身不会重新渲染影片。

准备较大的副本时可以取消。重试会沿用同一次请求；刷新页面后可以恢复准备状态。状态暂时无法确认时，界面会提示手动检查或重试。已经准备好的副本会保留，取消不会把它改成失败状态。下载使用浏览器的普通文件下载，请在浏览器中查看下载是否完成。

## 历史版本的变化提示更准确

版本页现在区分「工程内容有变化」「工程内容未变化」和「暂无法确认工程内容变化」。只有前后两份有效的完整源摘要都存在，才给出确定的比较结果。缺少证据的旧版本显示未知状态，已有历史记录保持原样。

## 使用范围

副本对应一个已保存版本，不是整个项目历史的导入包。仅用于观察的外部参考文件会被排除；同一文件若也用于模型或材质，仍会保留。原始 Blender 文件不被改写，因此上述排除不代表已移除其内部嵌入内容。

本次实际移动和打开验证针对上述宝塔样例及平台，尚未验证编辑后保存、原影片重渲染、Windows 解压、网络文件系统或断电恢复。Blender 原文件内的相机与动画设置保持不变；原始多镜头影片仍依赖插件的镜头编排。导出器不会据此保证任意工程的全部资源自包含，也不替素材确认授权；包内许可信息保留原有声明。
