# 0.11.0 — 手工摆放后的音箱仍能一句话改尺寸

候选已通过验收，标准公开发布尚在完成。

音箱 2.0.0 / 2.1.0 全套手工平移后，可在同一项目调整宽、深、高，保留摆放、
外观、编织精度、摄影和按钮时序。尺寸绑定会拦住独立旋转或类型变化，避免保存
宽深颠倒的模型；旧项目、旧锁和独立 Blender 文件修改保护保持。

保存回执给出实际位移分组、结构生成器改变名单与当前动画键，避免将前控件和
后接线混作同一方向、把保留外观解释成尺寸没变。搬迁后的读取给出当前项目目录，
历史元数据不重写；交付只报告已核对事实与剩余问题。

真实 bai 一条任务完成 300×150×180→320×160×200，422.463 秒、13 工具/9 步；
保留 12 个旧根文件与原版 24 文件，登记三个可点击文件。独立重开核对 111 部件、
六组连接与五个帧位；两对固定条件图片和两个原生回执重放通过。一个错误比较请求
自动修正，原始失败保留。完整运行 42 套件通过，最终单元/契约 134/134、工具卡
10/10 与真实视觉 14/14 通过，来源边界见[完整记录](../speaker-assembly-continuation.md)。

实际 82 分及六条遮挡发现保留，手工基线脚垫/地面间隔也保留。不是全装配、
制造或外部艺术认证，也不把配方修改称为任意自然语言建模成功。

安装仍沿用[三条路线](../install.md)。GitHub、七包 npm、公开读回、三路线和
[社区更新](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/pull/6868)在发布阶段
继续完成；社区提交、合并和线上刷新分别核实。
