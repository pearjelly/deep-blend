# 0.32.0 候选 · 从交付任务保存可编辑工程

渲染完成后，在「导出」的任务卡点「加入可编辑副本」。工作台打开对应的已保存版本，并勾选所选 PNG 或 MP4。还可以添加同版本的其他图片与影片，随后点「准备下载」。

从旧版本的任务打开副本时，工作台选用该任务的版本。准备过程沿用已有的来源校验与恢复机制。

在同一工程中渲染 PNG 和 MP4，通过实际浏览器操作一次下载可编辑 ZIP。解压核对图片、影片和 `.blend` 均与各自的原文件逐字节一致。桌面和 390 像素窄屏测试均通过。见[专项验证记录](../validation/delivery-job-copy-1128.json)。

本页记录候选功能与专项验证，正式发布仍待版本验收。
