# 0.28.0 候选：给半搭接木条设置边缘倒角

本版本尚未公开发布。源码与专项验证已准备，完整冻结来源验收、候选 CI、最终安装及公开渠道核验仍待完成；当前已发布版本见 [0.27.0](0.27.0.md)。

胡桃木格栅垫配方升级为 1.2.0。创建时可设置 0–1 mm 的「边缘倒角」，默认 0.5 mm；0 保留锐边。保存后可在原作品继续改变间距和倒角，每次产生新版本，历史文件及原始配方锁保持。旧 1.0.0/1.1.0 项目使用原锁，1.1.0 保留间距参数，不自动取得倒角参数。

对象编辑器沿用半搭接的上下角色和双面预览。倒角值变化会清除旧预览；确认保存时，所用场景摘要须与已检查的草稿一致。手工改变受控宽度或移除接头后，装配参数编辑返回冲突；独立的材质、摄影及上下角色修改保持。

公开操作 `joint.halfLap.set` 新增可选 `edgeWidth`，单位为米，范围 0–0.005；0 移除宽度字段，省略则保持已有值。正宽度需要原生能力 `geometry.joinery.half_lap.edge_finish`。配方绑定新增 `recipe.half-lap-bindings`，用两根木条的无序 ID 配对定位接头，不改写上下角色。

原生编译先开互补槽，再对凸边倒角，保留凹槽的直角边。新配方为原控制面显式生成 UV，并保留原材质、相机和灯光。默认图片由真实 Host 渲染，720×540、24 samples；公开 PNG 仅移除元数据，像素保持。[预览来源及独立重开记录](../validation/timber-edge-preview-1121.json)

开发专项中，画廊创建、连续修改、恢复锐边、刷新、390px 控件和可编辑 ZIP 共 36 项通过。七份工程独立重开，均有七个闭合实体、十二处交叉，126 个采样格没有重叠；边缘偏移与所选宽度一致，三角形 UV 面积有效。另有十组原生检查覆盖角色交换、非均匀缩放与共同旋转、法线对照，以及失败时的网格所有权回滚。这些专项不是完整版本验收。[候选记录](../validation/timber-edge-candidate-1122.json)

仍仅支持已有半搭接范围内的静态正交长方体木条及其阵列/镜像。数值在输入范围内也可能因几何过窄而无法生成；当前格栅垫的 5 mm 情况被拒绝，原模型保持，用户应减小宽度再预览。旧源上原有退化 UV 不会自动重写。有限网格与采样检查不代表制造认证，也未宣称独立创作者验收。
