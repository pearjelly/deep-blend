# DeepBlend Studio 0.3.2

**A clearer Blender workbench, from first creation to saved revisions.**

## What changed / 本次更新

- A consistent orange DeepBlend identity, clearer cards and visible keyboard focus.
- **System / Light / Dark** appearance, remembered in the browser. Switching appearance keeps drafts.
- Recipe creation with labelled fields and an action bar that stays within reach.
- Scene contents beside the selected object editor; camera, lighting and assets follow below.
- Persistent apply/reset actions, an unsaved-change indicator and inline invalid-number feedback.
- Responsive layouts for narrow DSH panels and the standalone workbench.
- Updated documentation screenshots captured from a running DSH, Chrome and Blender.

工作台增加了浅色、深色与跟随系统外观。场景列表与对象编辑并排显示，创建与应用操作更容易找到。
参数修改后显示未保存提示；数值留空时就地提示，修正后再保存并生成真实预览。

## Install / 安装

```sh
dsh plugin --profile web add @deepblend/dsh-blender-bundle
```

Or install the prebuilt bundle:

```sh
dsh plugin --profile web add https://github.com/pearjelly/deep-blend/releases/latest/download/deepblend-bundle.tgz
```

Restart `dsh web`, choose **DeepBlend Studio** in a new session and open Blender in the sidebar.
Node.js **22.23.3+**, DSH **0.1.5-rc.2** and Blender **5.2.1** are required; MP4 delivery needs FFmpeg/ffprobe.
