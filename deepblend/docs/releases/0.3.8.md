# 0.3.8 — 从版本入口可靠查看对照

版本页的历史入口明确进入版本对比，以选中的保存版与当前作品配对；当前版选择相邻另一版，单版入口明确不可用。旧的查看模式、右侧选择与结构差异不再混进新对照。

差异读取绑定当前项目、存储位置、指针、模式、配对与请求次序。迟到的成功或错误不能替换后来查看的结果，回执指向另一作品或版本时会被拒绝。查看不创建、恢复或自动渲染，未提交修改保留。

已于北京时间 2026-10-11 06:16:01 正式发布到 [GitHub](https://github.com/pearjelly/deep-blend/releases/tag/v0.3.8) 与[七个 npm 包](https://www.npmjs.com/package/@deepblend/dsh-blender-bundle/v/0.3.8)。冻结连续完整入口通过，版本对比在 macOS/Linux 均为 55/55；确切提交与主线三项 CI、匿名全包核对、实际 bundle 下载、公开 CLI 及整轮三路安装均通过。包内实际执行平台为 macOS arm64，其他所含原生目标仅核对文件/许可。社区 PR #6868 已更新，仍等待上游审核。使用与边界见[版本对比](../version-comparison.md)，当前状态见[每日记录](../daily-releases.md)。
