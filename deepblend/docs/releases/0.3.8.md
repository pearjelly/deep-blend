# 0.3.8 — 从版本入口可靠查看对照

版本页的历史入口明确进入版本对比，以选中的保存版与当前作品配对；当前版选择相邻另一版，单版入口明确不可用。旧的查看模式、右侧选择与结构差异不再混进新对照。

差异读取绑定当前项目、存储位置、指针、模式、配对与请求次序。迟到的成功或错误不能替换后来查看的结果，回执指向另一作品或版本时会被拒绝。查看不创建、恢复或自动渲染，未提交修改保留。

本轮仍是候选；真实专项不代替冻结连续完整入口、确切提交 CI 与公开发布。使用与边界见[版本对比](../version-comparison.md)，当前状态见[每日记录](../daily-releases.md)。
