# 0.3.9 — 跨项目预览归属与读取恢复

切换作品或存储位置时先清理旧图片及下载地址，读取失败明确显示原因与刷新入口。成功回执须匹配当前项目及其图片地址；迟到、错误身份或停用后的读取不能替换当前查看。

刷新只读，保存版本、原始图片与未提交编辑保持。返回原项目可继续调整；已有的版本冲突仍需要用户明确处理。当前版本没有预览的情况与读取失败分别显示。

已正式发布到 GitHub 与七个 npm 包，冻结连续完整验收、确切候选及合并主线 CI、干净构建、匿名七包全部文件读回、三路公开安装与空缓存 CLI 均已通过。真实浏览器验证覆盖 macOS/Linux；实际成品包执行为 macOS arm64，其他所含原生目标核对文件与许可。社区既有 PR 已更新，等待维护者审核。使用与边界见[预览恢复](../preview-recovery.md)，正式状态见[每日记录](../daily-releases.md)。
