# 0.23.0：修复平面网格上的重复纹理

本版本已于北京时间 2026 年 10 月 27 日 10:27:58 在 [GitHub](https://github.com/pearjelly/deep-blend/releases/tag/v0.23.0) 公开，七个 npm 包与三条实际安装路线均已核验。发布来源为主线 ef584e6caca11ff223a9e05b4048b8bf7df8f96a；本页是发布后的记录，不改变原标签、模型或安装产物。

对 mesh 生成器定义的平面控制网格，现在可以在对象编辑中选择「保存时逐面重建 UV」，调整面内转向与重复倍率，再保存一个新版本。公开场景操作 entity.uv.project 可在同一补丁内分别修复两组正交木条。它保持几何、变换、修饰器、材质、摄影与旧版本；非平面面片和不支持的对象会明确拒绝。各面可重叠，适合重复纹理；不提供图集打包、跨面无缝、通用曲面展开或几何搭接修复。操作和原图见[逐面 UV 指南](../mesh-uv-projection.md)。
