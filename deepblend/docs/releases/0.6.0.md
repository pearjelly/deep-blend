# DeepBlend 0.6.0 候选 — 继续调整已有整套模型

已有音箱项目可在场景树直接修改宽、深、高，一次保存生成同一项目的新版本和真实
预览。外壳、内腔、开口与部件装配位置联动，保留独立修改的材质、倒角、修饰器、
摄影设置及原始版本。恢复历史会恢复该版本的整体尺寸。

智能体新增 `blender_recipe_parameters`，先读参数和版本，再条件保存。
保存来源和参数状态在同一事务发布；相同请求重试不会重复创建版本。
过期版本、无效参数、被修改的受控几何或损坏来源会拒绝保存，并保留当前项目。
作者 SDK 支持读取保存来源和生成受约束的普通场景补丁。

目前新功能的真实 DSH/浏览器/Blender 专项验证通过 24/24；摄影回归和最终界面截图
正在更新。完整 39 套验收、最终源码 CI、干净构建及三个公开发布渠道尚未完成，
本文件不表示候选已发布。原版没有几何绑定的配方仍通过部件编辑继续修改。

用法见[音箱尺寸说明](../sized-speaker.md)。真实 DeepSeek Agent 凭据仍待恢复，
脚本化工具调用与原生验证不计为自然语言任务成功或外部用户采用。
