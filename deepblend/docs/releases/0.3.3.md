# DeepBlend Studio 0.3.3

**Find installation blockers in one read-only check.**

新增 `deepblend-doctor`：集中检查 Node.js、DSH、pnpm、Blender 及可选 FFmpeg/ffprobe，报告全部问题和具体下一步。图片创作与 MP4 工具分别显示；缺少编码器不会阻断图片工具自检。

- Supported-version checks use the maintained DSH and Blender compatibility anchors.
- Executable overrides support custom installation paths, including paths with spaces.
- Each executable has an 8-second deadline; failing tools do not stop the remaining checks.
- `--json` produces a structured report; `--require-video` also requires MP4 tools.
- No profile, project or model credentials are changed. Raw child logs are omitted.
- Showcase provenance is checked against exact source, image, video and display-copy bytes;
  the existing clay inspection images are now included in the publication manifest.

After this version is published:

```sh
npm exec --legacy-peer-deps --package=@deepblend/dsh-blender-bundle -- deepblend-doctor
```

From the source checkout, use `npm run doctor` now.

The check confirms executable availability and supported versions. Plugin activation and rendering
remain separate checks in DSH. Windows command wrappers remain outside the validated scope.
