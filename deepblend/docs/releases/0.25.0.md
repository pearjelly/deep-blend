# 0.25.0 · 可编辑的木条半搭接

0.25.0 于北京时间 2026 年 11 月 11 日 20:49:35 公开，发布包从主线提交 `d87eb61` 构建。[GitHub Release](https://github.com/pearjelly/deep-blend/releases/tag/v0.25.0)

两组正交木条交叠时，可以一次切出互补的槽口。在工作台打开「调整 → 形状与轮廓 → 半搭接」，选中另一组木条，再决定当前组保留上半部还是下半部。点「预览槽口」可以检查同一处交叉的上下切面。点「应用并预览」会核对草稿与预览一致，再保存新版本。已保存的搭接可以从任一组木条检查或移除，历史版本仍可恢复。

半搭接适用于两组由静态长方体控制网格生成的木条。两组须正交相交，顶面和底面分别等高。阵列和镜像参数仍可编辑，槽口会随几何重算。智能体可以用 `joint.halfLap.set` 执行同一建模操作。独立工作台也会跟随浏览器支持的中英文偏好。[工具契约](../tool-contracts.md)

[GitHub Release](https://github.com/pearjelly/deep-blend/releases/tag/v0.25.0) 提供含两组木条的示例 `half-lap-starter.scene.json` 和一对槽口图片。完成示例后，在「版本 → 保存可编辑副本」选择搭接版本并下载 ZIP。完整解压后，打开对应版本的 `scene.blend`，即可在 Blender 里继续编辑。
