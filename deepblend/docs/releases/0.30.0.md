# 0.30.0 候选 · 给两组木条贴同一张图

在工作台素材库中选中已检查的照片，再选中半搭接的一组木条。勾选界面列出的另一组木条，即可用相同的重复次数与纹理方向为两组设置底色贴图，并保存为一个新版本。

这项操作使用局部材质，可以保留两组各自的粗糙度和其他贴图。已有程序纹理时，界面会要求确认替换。单组编辑仍可从同一入口使用。

以带 1.1.0 配方锁的 64 mm 胡桃木格栅垫实测。照片检查完成后，选择目标、确认和保存从八次操作减为五次，其中保存从两次减为一次。对照使用同一张木纹照片和相同机位。[实测记录](../validation/timber-image-binding-browser-1127.json)

安装探针也会使用已建立的 DSH 所有者会话读取项目目录。候选仍待完整验收。
