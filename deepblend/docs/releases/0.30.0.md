# 0.30.0 · 给两组木条贴同一张图

在工作台素材库中选中已检查的照片，再选中半搭接的一组木条。勾选界面列出的另一组木条，即可共用底色贴图、UV 层、平铺和偏移设置，并保存为一个新版本。需要调整纹理方向时，可在「形状与轮廓」中对两组一起重建 UV。

两组使用独立的局部材质，保留各自的粗糙度数值和其他图片贴图。确认替换程序纹理会移除其生成的颜色、凹凸和粗糙度起伏。单组编辑仍可从同一入口使用。

以带 1.1.0 配方锁的 64 mm 胡桃木格栅垫实测。照片检查完成后，选择目标、确认和保存从八次操作减为五次，其中保存从两次减为一次。在 Blender 独立重开保存文件后，两组材质的粗糙度分别为 0.44 和 0.57，底色节点使用同一张内嵌照片，几何和摄影保持一致。[实测记录](../validation/timber-image-binding-browser-1127.json)
