# 整灯摆放候选：移动、转向、落到表面后继续修改

本功能正在开发，尚未随稳定版本发布。当前已发布的 0.20.0 支持整灯摆好位置后的尺寸修改；这轮把完整台灯的移动、转向和实际表面放置合并为一次保存，随后继续使用原尺寸入口。

## 先实做旧版任务

2026-10-26 使用发布主线 `1cb54abb94d1a9c1fa8329dcd9c87d640ed82803` 的真实 Host 和 Blender，建立包含 23 个产品部件、地面、有限斜面和无关标记物的隔离项目。先绕世界 `(80,-30,0) mm` 的竖轴转向 35°，再沿世界坐标平移 `(200,-100,150) mm`，目标竖直间隙为 1.5 mm。

旧版一次底座放置只移动底座，随后尺寸修改因装配错位被拒绝。将该底座位移手动同步到全部部件后，整灯最低处仍低于斜面约 1.708 mm，距离目标间隙短缺约 3.208 mm。独立检查完整求值顶点后再次整体修正，才得到完整装配的 1.5 mm 间隙，并完成 250→230 mm 续改。最低部位是底座毛毡脚，不能把底座主体或某个对象原点当作整灯最低处。

实际探索路径包含三批、每批 23 条变换，以及失败对照和修正；这不是完成任务的最少操作数，也不是模型耗时对照。旧版通过手工操作可以完成任务，没有预设旧版模型必须失败。保留原摄影的最终旧版图片裁切了上部，说明摆放正确和构图合适需要分别检查。

早期检查器把求值多边形顺序变化误作几何差异，另一次把新增预览索引当作历史内容变更。原失败记录保留。后续核对完整有向多边形、每个局部顶点、生产回执绑定的原生摘要和保存的场景文档；既有几何容差没有因面序问题放宽。预览只追加索引，源场景和原生内容仍按原摘要检查。

## 一次明确的整体请求

继续使用 `blender_place_on_surface`，不增加工具数量。默认或 `scope:"entity"` 保持原单实体语义。整灯必须显式选择 `scope:"recipe-assembly"`，并使用 `blender_scene_get` 返回的 `assemblyPlacement.subjectEntityId`。Host 从已保存的台灯 2.2.0 原始锁解析完整 23 件，调用方不用手写成员列表。

```json
{
  "projectId": "my-lamp",
  "baseRevision": "r0002",
  "scope": "recipe-assembly",
  "subjectEntityId": "weighted-base",
  "supportEntityId": "table",
  "frame": 24,
  "clearanceMm": 1.5,
  "pose": {
    "translationMm": [200, -100, 150],
    "yawDegrees": 35,
    "pivotMm": [80, -30, 0]
  }
}
```

`translationMm` 是相对世界 XYZ 位移；`yawDegrees` 是相对竖轴转角，从上方看逆时针为正。先绕世界 `pivotMm` 转向，再平移，最后沿世界 Z 根据实际支承面调整高度。省略枢轴时使用当前已保存的底座原点；省略位移和转角时均为零。输入的 Z 是落到表面前的暂定高度，最终高度由接触计算决定。位移和枢轴各轴限于 ±1000000 mm，转角限于 ±360°，间隙限于 0–1000 mm。

测量覆盖电线、灯泡、底脚等全部成员的真实求值网格。候选保存前独立重开基线与候选，逐件核对同一个刚性世界变换、完整顶点、有向拓扑、UV、材质及支承不变。回执绑定源修订、原生摘要、配方原点、完整成员、接触所属部件、明确帧和目标间隙。重复同一请求沿用原标识返回原结果，不再次移动。

缺件、单件错位、缩放或倾斜、受控几何冲突、产品成员动画和相关几何依赖会拒绝整次保存。支持面必须在装配之外。原修订、材质、未受控细节、相机和灯光保持。整体转向保持直立；间隙沿世界竖直方向计算，不是沿表面法线的距离，也不证明物理稳定或移动路径无碰撞。

## 工作台入口

「调整」中的「摆放整盏灯」选择支承对象，并输入世界 X/Y 位移、转向变化和竖直间隙。旋转中心、暂定 Z 位移与测量帧放在可展开的精确设置里。输入不会立即保存或渲染；明确保存后生成一个新版本和该帧预览。

失去响应时保留原请求与标识，允许重试同一次放置。取消后读取真实保存状态；切换作品或存储位置后不会采用旧请求的提示。已有新版本或其它未保存草稿时须先处理。大幅移动后检查构图，需要时明确调整摄影。

## 当前验证与剩余门槛

原生专项已实际通过 34 项检查：水平支承整体平移、斜面上绕指定枢轴转向、全 23 件的独立顶点/矩阵与同尺寸原生对照、1.5 mm 完整装配间隙、250→230 mm 续改、历史保护，以及真实候选漏动最后一个部件时整次拒绝。固定相机在任务开始前设为 42 mm；两张最终实图完整可见，不能称为操作自动重构图。

维护者这次实测水平放置约 10.055 秒，斜面放置约 97.951 秒；尺寸续改分别约 2.015 和 2.039 秒。这些是同机直接 Host 操作耗时，不是自然语言任务耗时或速度提升结论。UV 对照另允许 0.000001 的重建数值误差；实际旧版刚性对照中的最大 UV 差为约 `5.96e-8`，几何检查仍独立执行。

浏览器最初通过 23 项检查，独立界面复核随后发现预览目的页隐藏了成功提示。修正后，同一实际任务完整复验通过 28 项检查：一次整体放置、两次尺寸保存、页面重载、独立原生结果、原始 PNG 来源和历史字节保护，以及桌面与窄屏的两种预览模式完成提示。提示绑定当前作品与存储位置，明确已保存的 23 件、修订号和构图提醒。原始失败保留；同一复核员仅对该问题复判为已解决，不扩称整个界面重新审查通过。

真实模型同任务对照、冻结来源的连续完整验收、确切提交 CI、最终主线构建、全新安装与公开发布读回仍待完成。本页的专项结果不替代这些门槛，也不代表任意装配、任意自然语言建模或外部用户采用已验证。
