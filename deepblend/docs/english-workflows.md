# 英文核心工作流与预设入口

## 需求与范围

外部 [issue #45](https://github.com/pearjelly/deep-blend/issues/45) 点名五篇高频指南的英文配对和共享术语。本轮开始时，工作台已跟随 DSH 的 document.lang 使用中英字典，工具说明与主模型技能也已有英文；这些既有功能不计为新增。剩余入口包括中文预设列表描述、五篇主要操作手册，以及英文 README 指向中文手册的导航。

0.24 候选增加以下任务指南：

| 指南 | 任务 |
| --- | --- |
| [Using DeepBlend](usage.en.md) | 创建、草稿、对象编辑、版本比较、PNG、可编辑副本与交付 |
| [Modeling](modeling.en.md) | 旋转体、连体杯、曲线、网格、修改器与逐面重复纹理 UV |
| [Photography](photography-editor.en.md) | 摄影草稿、保存后的重试、完整取景与复用旧作品摄影 |
| [Recovery](recovery.en.md) | 中断恢复、编码、审批、并发版本、存储和错误码 |
| [Tool contracts](tool-contracts.en.md) | 全部现行工具、顶层参数和场景操作词汇 |

两种语言互链，英文 README 与文档入口直接指向英文页；CONTRIBUTING 增加术语与配对维护约定。英文页提供连续任务说明，中文原页保留历史实验、图片与专门细节。两项预设的列表描述增加英文，开发预设名增加英文；规范源经 presets:sync 写入安装副本。英文指南与双语预设部分没有改模型提示词或工作台实现。主线随后合并的独立创作功能另含运行时和工作台改动，需要单独完整验收。

回归还暴露了本机 Node 24.13.0 删除目录符号链接失败的问题。源码安装事务改用 unlink 删除目录项并保留目标包，范围与最小实测见 D299；这是源码安装工具的兼容修复。
