# 有界实体复制候选

2026-10-15 写入前实测：宝塔项目r0044的已保存单簇宽叶实体紧凑JSON长4106字符。
逐字重复100份需410600字符，这只是输入体积乘法，不是实际任务用时推算。
现有scene_patch不声明entityCopies，空operations返回SCENE_PATCH_INVALID。
原始探针位于`.tmp-entity-copies/before.json`。

候选在正式工具平面把显式指定的单实体复制请求展开为已有的entity.add操作，仍由
Host执行原来的原子校验、冲突、历史、原生编译和幂等保护。每次至多16份，来源固定为
baseRevision，不能引用本批新副本，不覆盖已有ID。仅支持可选的绝对transform分量覆盖；
复制所有其余实体字段，但不复制动画轨道或递归装配，也不重新映射材质/布尔/父级引用。
这不是自然树冠生成器或自动放置，模型仍须决定位置并检查实际接触和图像。

后续整体位移探针确认：工具尚未声明共同位移，复制仍保持原位置。新增可选
entityCopyOffset:[dx,dy,dz]，将显式所选副本共同平移世界米制位移，以保留枝叶/部件
相对位置。它与任一副本的绝对location覆盖互斥；不会自动选择部件、移动未选依赖
或复制动画。平移前后仍需原生核对。该扩展的验收待完成。
