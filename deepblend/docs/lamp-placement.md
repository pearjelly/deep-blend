# 已摆放台灯的参数编辑（0.20 候选）

目标任务：台灯已经放在场景中并转向，用户只需把灯罩直径改为 250 mm，再改为 230 mm；整灯位置、朝向、外观与当前摄影保持，内外壳、弯臂和支架继续正确连接，每次保存可编辑的新版本与指定帧预览。

台灯 2.2.0 原有 180–250 mm 直径范围，以及超过 230 mm 时支架与弯臂退让的联动，均是已有功能。本轮新增的是在场景中整体摆放后继续使用这些参数。0.19 的原位编辑可用，但统一平移或竖轴旋转后的同一整灯会被参数规划器拒绝。只检查受参数控制的部件还会漏掉单独移走或删除灯泡的情况。

候选只识别已保存的台灯 2.2.0 原始配方锁。以不随直径变化的底座为参考，核验锁内全部 23 个产品部件确实共享世界 XYZ 平移与竖轴旋转（yaw）；各部件保持正单位缩放，地面不属于这 23 件，额外场景物体保持。旋转按 XYZ 弧度解释并比较等价旋转矩阵，允许整周不同的表示方式，保存的原始旋转数组不改写。

新尺寸始终从当前参数的原配方锁求出，再映射到已经确认的摆放位置。八个支架沿台灯自身方向联动，因此转向后的世界 X/Y 都可能变化；弯臂的路径仍在其物体局部坐标中修改，不能再旋转一次。材质、细分、倒角等未受控编辑和摄影继续保留，既有保存、重试和恢复版本入口保持。

缺部件、独立挪动或旋转一个部件、非单位缩放、整灯倾斜、受控轮廓或弯臂路径被改造均会提示冲突。锁内产品部件带有变换动画、骨架或刚体/布料/软体/流体状态也不属于静态编辑范围；无关实体的这些状态不受影响。这不是对任意台灯、任意装配、烘焙变换或所有未受控造型的通用识别。旧版 2.1.0 原位兼容修复保留，不借用新的姿态豁免。

验收必须同时证明世界位姿与局部几何正确。仅把实际底座求逆后比较形状，会漏掉整灯一起被放错位置的错误；独立重开每次 `.blend` 后，还须与预先固定的世界矩阵比较全部成员的旋转、位置与正单位缩放，再检查局部全网格、三处壳厚/内衬间隙和既有支架相交条件。同一相机、帧和画面条件下的预览必须与保存版本绑定。

原生世界矩阵在摆放编辑前由原锁与目标直径独立生成，局部全网格参照保留相同的材质、细分和倒角编辑。容差只用未改尺寸的刚体摆放校准，并在任何续改或负对照前冻结：局部顶点容差为 0.000429815 mm，低于 0.01 mm 硬上限；十二次摆放尺寸检查的最大误差为 0.000053727 mm。固定相机的求值事实逐项完全一致，75 份历史场景、原生、配方锁及预览文件保持字节不变。

首次原生运行 63/64 因 Blender 球体的面列表顺序差异误报；独立检查确认顶点逐项完全相同、有向面一致。测试仅规范化面循环起点和列表顺序，保留绕序、重复次数与全部顶点约束。UI 首轮 19/20 因 JSON 对象键顺序误报，第二轮完成 22 项后因等待错误的图片区超时；分别改用结构比较和明确版本/摘要的比较右侧图片等待。三轮失败及修正后的完整新运行均保留，产品代码未为这些测试错误修改。
