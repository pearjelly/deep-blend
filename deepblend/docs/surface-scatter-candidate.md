# 静态封闭表面布置候选

2026-10-16，宝塔案例的真实插件项目r0049已有39簇宽叶，36个新增副本和原有3簇的
原生根部均进入实际木枝，287个受保护文件不变。然而r0050整株渲染仍明显稀疏，侧面
机位被建筑遮挡，观感不通过。数量与原生连接通过不能替代实际冠形。当前叶簇只集中
在7个已检查支撑点，逐个列出大量新坐标既昂贵又容易出现错误；此前4份副本中3处
曾经未充分嵌入，原始失败及后续修正保留。

写入前探针：surface_scatter仍被SceneSpec以SCENE_SCHEMA_INVALID拒绝，记录保存在
`.tmp-surface-scatter/before.json`。这不是已发布功能。

候选为通用、确定且有预算的modelModifier，使用模型已保存的原型和实际封闭目标网格：
模型显式指定1–8个目标、1–512份数量、种子、原型原生连接顶点及尺寸/朝向变化。
运行时按实际三角面面积采样，测量向内弦长并选择嵌入深度，只有指定连接顶点全部
进入目标才接受该实例。随机尝试有固定上限；未能完成数量则明确失败，不保存半成品。
预先限制总顶点、面和UV角数，不开放脚本或表达式。

仅支持静态、单网格生成器；原型/目标不得绑定骨架、物理或变换动画；布置必须位于
原型修改器栈最后，目标不得再含布置修改器。输出为可编辑原生网格，原型、参数、
种子与依附证据保存在SceneSpec及原生元数据中。依附在重新构建时计算，不声称实时
骨骼绑定、整网格无碰撞、有效联合体积或照片级质量。旧项目未使用该类型时保持原行为。

需要完成契约、原生UV/连接/确定性/预算/失败隔离、UI镜像和完整验收，再由真实模型
通过正式插件调用，在相同条件下看冠形与完整视频。本页不作为这些验收已通过的记录。
