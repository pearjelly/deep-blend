# 按尺寸创建桌面音箱

这项功能已在 [0.5.0](https://github.com/pearjelly/deep-blend/releases/tag/v0.5.0) 发布。它支持按尺寸创建新模型。下述已有模型编辑是 0.6.0 新增功能。

在工作台「项目」页选择音箱 2.0.0，填写箱体宽、深、高。单位都是毫米，默认值为 264、138、162。可用范围分别为宽 264–340、深 138–180、高 162–220；超出范围时，创建按钮会提示你先修正。

例如，只把宽度改为 **300**，保持深 138、高 162，填写项目名称，点击「创建并生成预览」。完成后可查看主图，继续编辑部件、材质或摄影设置，并保留可重新打开的 Blender 模型。创建耗时取决于设备。

尺寸调整会联动外壳、内腔、前后开口和盖板。格栅、旋钮等零件保留自身尺寸，并跟随装配位置移动；底面高度保持不变，顶部按钮的按压行程也会保留。摄影机跟随对应尺寸或部件。图库示例图展示默认尺寸，你的实际输入会在创建时重新渲染。

颜色、粗糙度和摄影曝光仍可分别调整。选择其他配方再返回时，未提交的设置会保留；「恢复默认参数」只重置当前配方。成功创建后，旧项目的来源、模型和预览不会因图库升级而被改写。

当前已通过真实浏览器创建、独立打开 Blender 文件和尺寸边界验证。箱体与内腔的边界差保持不变；这不等于最小壁厚或制造认证。导出前仍应检查用途所需的几何和成品质量。

接口与原版兼容记录见[配方说明](recipes.md)，继续工作的方向见[复杂建模计划](complex-modeling-roadmap.md)。

## 继续修改已有音箱

打开使用音箱 2.0.0 创建的项目，在「场景树」的「调整整套模型」中改宽、深、高，
点击「保存整套尺寸并预览」。例如将已保存宽度 300 改为 340、高度 162 改为 200：
一次保存得到同一项目的新版本和真实预览。独立修改的材质、倒角、修饰器和摄影设置保留。
修改过的镜头会保持原样，请查看新尺寸下的构图。正常配方镜头会跟随尺寸与部件。

原模型、来源与预览继续留在版本历史；恢复旧版本后，三个输入重新显示旧版本的尺寸。
没有提交的尺寸草稿会保留在当前页面的对应项目中；页面重载读取已保存尺寸。
如果还有其他未保存编辑，请先保存或放弃它们。页面提示版本变化时，审阅新版本后
点击「放弃草稿，重新载入」，再修改；不会偷偷把旧草稿套到新版本。

如果单独修改了受联动控制的几何，整套保存会被阻止，并列出相关部件。
点击部件可进入局部编辑，恢复对应尺寸或位置后再调整整套模型；也可从历史恢复到
合适的版本。系统不会覆盖手动修改来强行完成联动。

原版音箱 1.0.0 没有声明整体几何参数，继续使用部件编辑。普通项目和其他没有几何
绑定的配方也不会出现整套尺寸入口。

智能体使用 `blender_recipe_parameters`：先读取当前版本、参数和范围，再提交保存。
作者可通过公开 SDK 的 `instantiateRecipeLock` 与 `planRecipeGeometryEdit` 验证保存来源、
生成普通场景补丁；它们不会启动 Blender 或直接写项目。

## 手工摆放后继续改尺寸（0.11.0 候选）

已保存的音箱 2.0.0 / 2.1.0，如果把全部 110 个模型部件（地面除外）共同平移，
并将按钮动画的静止锚点一并移动，可以继续用三个尺寸输入或一句话修改；整套位置保留。
例如“把这台音箱改成宽 340、深 180、高 220 毫米，保留摆放、材质和摄影”。
原始锁不升级，旧 Blender 文件和预览保留。

仅移动箱体、落下接口或电缆、单独旋转受尺寸控制的箱体或盖板，会列出冲突并阻止
整套重建。不会自动复位手工部件。整套旋转暂不支持此接续；普通局部编辑继续可用。
定制摄影不会被重置，调整尺寸后需检查构图。详见[装配探针与验收](speaker-assembly-continuation.md)。
