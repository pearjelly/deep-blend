# 部件几何摘要：0.8.0 后的测量与下一切片

状态：未交付原型，不升版、不计真实模型提速。

真实 bai 灯具编辑此前 19 次工具调用里有 14 次 grep、4 次无匹配，grep 文本 26,364 字节。当前 scene_get 摘要提供形状/材质/位置，没有逐部件尺寸和完整变换；scene_validate 的已记录技术摘要只有合计顶点/面数。编译器可产出逐对象 worldBounds，但当前模型读取路径没有这些数据，不能把声明中的参数当作实测。

只读打开同一真实任务 r0002/r0003，选择灯罩、内衬、弯臂、颈部、灯泡与关节六部件，输出 3,634/3,631 字节。摘要包含实体 ID、实际评估网格数量、世界包围盒/各轴跨度、缩放、矩阵、帧、Blender 版本、源摘要、原生/场景/manifest/检查器哈希。规范场景摘要与 revision manifest 一致，全部原版本文件哈希保持；六部件各轴跨度与此前独立原生检查报告一致，外径 209.8→230 mm，四个保护部件的本次原型数据完全一致。

这些跨度是所选帧世界轴包围盒，不是内在直径、法向壁厚、净间隙、碰撞判定或成品认可。3.6 KB 只是输出大小，不能直接声称 token 或耗时改善。没有调用模型、审查器或渲染，没有接入 Host/工具/UI。

实施顺序：PR42 的确切提交四作业已成功并显式合并为 d10bc73，现从该主线建立独立产品分支。复用既有场景检查入口提供少量指定实体的可选只读测量，默认旧输出保持；显式帧与确切 revision、规范 spec 摘要和读取原生哈希绑定。没有 checkpoint、手改文件、未知/重复实体、过大选择、不可测对象、取消和旧报告应给出明确结果，禁止静默伪造数值。不要把几何摘要写成建模审查通过。随后实际音箱/厚壁杯/灯具检查旋转缩放和装配，再以同任务/provider/preset 记录少量操作、返工和真实完成耗时。

源代码原型与原始日志保存在 .tmp-geometry-summary-probe-v1，当前正式稳定版仍为 0.8.0。

跨基线补测：正式厚壁杯输出 826 字节，原模型音箱基线输出 2,776 字节。杯的世界 X 跨度约 125.84 mm 含把手，不能冒充 84 mm 杯身外径；音箱隐藏视口的 rear-service-tool 在初始原型中返回不可信评估值，原结果保留。第二版对该对象返回 evaluationAvailable:false 和空包围盒/跨度，四组只读检查通过。台灯六部件仍可测。

仅有包围盒不能回答原任务的壁厚与内衬间隙条件。本次额外组装两份任务相关回执，明确复用此前独立 native 检查的三处法向采样，并以完全相同的原生 checkpointSHA 绑定；来源报告哈希与“历史测量重放”标签保留。它没有新增全表面采样。实施时需原生测量接口提供受支持几何的采样协议与来源校验，不可由轴跨度或配方声明推导壁厚/净间隙，也不可把灯具特定采样硬写成任意对象能力。
