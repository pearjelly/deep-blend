# Cairn 264：可重建桌面音箱基准

原创单声道桌面音箱。暖白圆润柜体包围深色前障板，左侧大面积编织格栅与右侧小型金属控制组件构成主次。相机观察的是完整装配的产品，不是零件拼贴或爆炸图。此概念不对应现有品牌，不声称已完成声学、电子或量产设计。

## 固定参数

| 项目 | 固定值 |
|---|---|
| 柜体 | 宽 264 × 深 138 × 高 162 mm；底部离台面 14 mm；外轮廓顶高 176 mm |
| 前格栅 | 外环直径 121 mm；有效织物直径 107.5 mm；左侧圆心 x = −48 mm、z = 99 mm |
| 格栅细节 | 纱线直径 0.64 mm、间距 1.8 mm；经线在交叉点前后交替，纬线居中；真实几何、有间隙 |
| 控制组件 | 独立前板宽 74.2 mm，独立垫圈；44 mm 旋钮、11 个刻度、44 条细滚花、两个输入键、三颗指示灯 |
| 结构 | 开口空腔柜体、独立前障板、后检修板、九道贯通散热口、四个开槽螺钉、两处输入结构、四个橡胶脚垫 |
| 时间 | 24 fps；帧 1–48；唯一运动是顶部按钮下降 0.7 mm 再返回，帧 1/24/48 均保持装配 |
| 相机 | `hero` 前方右侧三分之四；`detail` 格栅与控制组件；`reverse` 背板与接线；`motion-detail` 固定 85 mm 镜头观察顶部按钮 |
| Preview | Cycles、768×576、64 samples、AgX、exposure 0 |
| Final | Cycles、1024×768、128 samples、AgX、exposure 0 |

长度使用米，以上毫米值为说明。面数上限为整个评估场景 150,000，包括隐藏布尔操作数；实际以 Blender 编译后的网格统计为准。地面标记 `environment`，供灰模流程保留。`geometry-checks.json` 列出独立检查的封闭实体和世界包围盒尺寸；尺寸允许 ±0.2 mm 误差。

## 几何审阅

1. 三个机位应都能辨认柜体圆角；壳体不能表现为数个没有结构关系的方盒。格栅外环、前障板、控制模块和后检修板之间应有清楚但克制的接缝。
2. 格栅线材应有体积、交叉和暗处空隙。细节机位应能看见后面的驱动单元暗部；不可用一张高对比棋盘纹理冒充织物。经纬线交点的中心深度差为 0.7 mm，大于两线半径之和 0.64 mm。
3. 金属旋钮的肩部、前面、细滚花、嵌线和刻度应分别可读；刻度落在控制板范围内。旋钮不能像漂浮圆盘，橡胶座圈应与面板连接。
4. 后面九道散热口和螺钉槽必须来自布尔差集。脚垫落地，有接触阴影；线缆应连接背面接口并自然落地，不能穿入柜体或台面。
5. 帧 1、24、48 除顶部按键外，所有实体的变换保持一致。按键下压 0.7 mm 后仍高于座圈，不能散件、穿插或放大缩小整机。动画使用固定 `motion-detail` 机位，保留按键、座圈和周围外壳；384×288 视频中按键顶面预期下降约 6.85 像素，帧 48 回到帧 1 的位置。不得通过移动相机或夸大行程制造可读性。

## 材质与灯光审阅

- 暖白喷涂外壳、粗糙编织格栅、深石墨面板、香槟色阳极金属和哑光橡胶应有不同的高光宽度与表面尺度。
- 细噪声只用于小尺度表面粗糙感，实际格栅、接缝、滚花不依靠 bump。不得用提高采样掩盖几何问题。
- 主光为 8.5 W 暖色大软箱，2.8 W 冷填充留住黑色面板的层次，11.5 W 后光描述边缘；额外 1 W、宽 0.4 m 的后侧软填充位于 [−0.35, 0.25, 0.30]，朝向 [0, 0, 0.09]。这盏弱补光衔接后侧圆角的明暗，避免三盏主灯方向之间出现突兀竖向暗带，同时保留体积。香槟金属的亮部应保留颜色，暖白外壳不应整体过曝。
- `hero` 先读整机外形，再读大格栅与旋钮；背线和小指示灯不应抢过主体。`detail` 允许裁切外壳边缘，必须保留旋钮与足够的格栅交界。`reverse` 必须显示后板、螺钉和接线，不能只拍到壳体背面。
- 不使用景深模糊隐藏缺陷、不添加后期锐化或自动曝光差异；三视角按相同渲染设置比较。

## 消融对照

`baseline-scene-spec.json` 是同一设计的几何与材质同时简化对照，**不是历史旧版本**。它保持相机、所有原有实体变换、世界、灯光、镜头、曝光、shots、动画轨迹和渲染规格；去掉壳体倒角与多数布尔结构，将车削件简化为低分段圆盘，隐藏细滚花与刻度，以实心盘代替编织。仅保留外壳的后检修开口减法，避免实心外壳与原位后板的外表面共面而产生黑色伪影；开口操作数也简化为方盒，不保留通风或螺钉槽等细节。产品材质统一为中灰非金属，地面不变。

这能回答“精细几何与材质分区一起是否改善作品”，不能把差异单独归因于某一种建模能力。正式判断应并排查看同帧同机位图片，结合灰模和网格统计；技术验证通过不等于艺术质量通过。

## 重建与限制

```sh
node deepblend/benchmarks/modular-speaker/build.mjs
node deepblend/benchmarks/modular-speaker/build.mjs --check
node deepblend/tools/quality-benchmark.mjs --case modular-speaker --check
```

`build.mjs` 只生成公开 SceneSpec，运行 contracts 的 validate/compile，并检查对照条件一致。无需资产下载、外部贴图或字体，不调用自定义 bpy 造物。全部网格及隐藏布尔操作数均在 SceneSpec 中声明。主要使用 `rounded_box`、`lathe`、`curve`、局部位移 `array` 和 `boolean`。

限制：这是外观与装配表达，不模拟织物张力、声学或制造公差；“喷涂”“阳极金属”是材质目标而非完整工业 BRDF。近距离极高分辨率可能显露简化线材与低分段滚花。`build --check` 不证明布尔拓扑、面数、法线或实际视觉品质，这些必须由真实 Blender 编译与图像审阅确认。
