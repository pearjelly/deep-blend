# Arc No. 01 — 香槟金属桌灯基准

## 固定目标

做成可重复重建的产品摄影场景：暖灰环境中的香槟拉丝金属桌灯。视觉重点是连续的旋压灯罩、圆润开口、细长弯臂、稳重底座，以及大面积柔光在金属上的连续变化。整体应有真实装配关系，不能依靠黑背景隐藏接缝或仅靠材质掩盖低细分轮廓。无品牌、无外部贴图、无有版权素材。

`scene-spec.json` 是成品候选，`baseline-scene-spec.json` 是刻意简化的消融对照，**不是历史旧版本**。两份文件都由公开 SceneSpec 能力表达；`build.mjs` 只计算数值、验证契约并写 JSON，不调用 Blender 建模接口。

## 尺度与装配

单位为米，所有物体 scale 均为 `[1,1,1]`；倒角宽度就是场景中的物理宽度。

| 项目 | 固定尺寸 / 位置 |
| --- | --- |
| 总高 | 约 455 mm，具体顶点边界由曲线离散化决定 |
| 圆底座 | 直径 209 mm；底座上表面 25.5 mm；独立 3 mm 深色脚垫接触地面 |
| 灯罩 | 开口直径约 210 mm；从 313.4 mm 到 430 mm；轴心 X=45 mm、Y=0 |
| 灯罩壁 | 闭合截面形成约 1–2 mm 金属壁和卷边；不是单面圆锥 |
| 内衬 | 独立约 0.25 mm 暖白珐琅层，止于卷边内侧 |
| 主杆与弯臂 | 主杆直径 14 mm、轴心 X=-75 mm；弯臂直径 12 mm；单位尺度曲线扫掠 |
| 关节 | 直径 32 mm，轴向沿 Y；前后端盖、细环和中心轴 |
| 旋钮 | 直径 22 mm，位于底座前右侧；含凹座与方向刻线 |
| 电线 | 直径 4.4 mm，后方出线；地面段中心高 2.3 mm，避免悬空 |

灯罩采用 128 个径向段和 97 点闭合截面；主形曲线通过明确的三次 Bézier 控制点采样。内外壁、唇边都属于实际网格。该截面与底座轮廓优先于增加小零件数量。

## 机位、动作与灯光

- `hero`：65 mm，4:3 三分之四全景。固定焦点 `[0.014,0.025,0.228]`，相机半径 1.3 m、高 0.52 m，48 帧内缓慢绕行 8°。位置与朝向都写入关键帧 1、24、48；灯具装配保持静止。
- `detail`：70 mm，较低机位，观察开口厚度、珐琅内衬及灯泡。局部构图允许底座不在画面内；关节连接由 reverse 视图检查。
- `reverse`：58 mm、高 0.585 m、目标点 `[0.04,0.07,0.20]`，背面全景，用于检验杆件、关节连接及后盖、出线口、完整线缆的贴地关系与表面连续性；较高俯角避免把世界背景与地面的边界带入画面，较低目标点为线缆下缘留出空间。
- 世界光明确为冷中性 RGB `[0.18,0.19,0.22]`、强度 0.24。
- 四盏明确面积光：大柔光主灯、偏冷侧后轮廓灯、低能量正面补灯及顶部高光灯。金属靠实际反射区分明暗，不通过提高基础色模拟发光。
- 灯泡是暖色发光表面；其下方的低能量点光提供小范围实用照明，避免把点光埋在不透光灯泡内。
- 预览：Cycles、768×576、64 samples、AgX、exposure 0。
- 成品：Cycles、1024×768、128 samples、AgX、exposure 0。
- 24 fps，frameStart=1、frameEnd=48。对照共享所有机位、动画、灯光、世界及曝光值。

## 固定审阅画面

固定审阅包含 `hero@1`、`hero@24`、`hero@48`、`detail@1`、`reverse@1`。对照至少输出 `hero@1` 与 `detail@1`。以文件中的声明分辨率做最终判断；低清图只用于发现裁切、穿插和严重曝光问题。

### 几何与构图

1. 三个 hero 帧应完整包含主体，保持相近尺度；不能出现灯罩或底座裁切、姿态跳变、主杆与灯罩误连、漂浮或明显相交。
2. 主灯罩外轮廓在 1024 像素成品图上不应出现多边形折线；其大面积高光也不应出现分段明暗条带。
3. detail 能读出实体唇边、空腔和内衬；外壳不能像实心锥体，内衬不能穿出外壁或闪烁。
4. 弯臂应连续光滑并实际接入关节、颈圈；杆件与底座套筒接触，关节盖不悬空。
5. 底座轮廓、接地暗线和软阴影成立；电线在背视图沿地面延伸，无明显埋地或悬浮。
6. 对照图应能显示径向低细分、简化曲面、缺失细环/刻线造成的差异，不能通过移动机位或改变曝光放大差异。

### 材质与灯光

1. 金属呈暖灰香槟色，宽柔光中保留中间调和较暗反射区；不能整片纯白、镜面铬色或塑料黄色。
2. 拉丝纹理只在细节和高光变化中可辨。不能像木纹、粗噪点、锤纹或橘皮；英雄全景优先读形。
   灯罩、底座、旋钮和关节端盖使用 Principled `anisotropic=0.55`，显式 `radial/z` 切线沿各自物体局部 Z 轴的圆周展开；端盖的物体旋转会把轴带到关节方向。`anisotropicRotation=0`，不把高光转到轴向。细尺度噪声只提供轻微表面变化；弯臂与直杆保持较均匀的细磨金属，避免在非旋转曲线上套用错误的径向切线。
3. 大灯罩、高光边缘、深铜关节、珐琅内壁、橡胶脚垫与织物电线应有清楚但克制的材质差异。
4. 暖灯泡可局部接近白，但不应吞没唇边；主灯罩的金属高光不应大面积剪切。
5. 底座与地面有柔和接触阴影；侧后轮廓灯不能产生突兀蓝边，顶灯不能在壳体上形成过曝硬斑。

## 对照的消融范围

对照保留产品位置、尺度、主要装配与照明意图，作如下主动简化：

- 径向段数降至 16，球体纬圈降至 8；曲线分辨率降至 4、截面细分降至 2。
- 灯罩与内衬改为少量直线截面；底座用 16 段闭合车削截面表达同外径和高度范围的无倒角圆柱形，保持原点及实体变换一致。
- 去掉生成器倒角及 6 件细节：底座细暗缝、杆套细环、关节细环/中心轴、颈圈亮边、旋钮方向刻线。
- 去掉所有程序纹理、各向异性及其切线节点、主金属薄清漆，保留相同主色、metallic 与 roughness。

这是“几何细节 + 表面细节”的联合消融；不能据此独立归因单个参数，也不能把候选优于此对照作为外部竞品质量排名。

## 重建与验证

从仓库根目录运行：

```sh
DEEPBLEND_DSH_ROOT=$PWD/.tools/dsh PATH=$PWD/.tools/dsh/node_modules/.bin:$PATH node deepblend/benchmarks/metal-lamp/build.mjs
```

脚本对两份文档分别运行 `validateSceneSpec` 和 `compileSceneSpec`，并断言相机、shots、animationTracks、world、lights、renderProfiles 及所有同名实体的 transform 完全一致。加 `--check` 可检查落盘文件与重建结果逐字一致且不写文件。当前两份均通过，零校验通知、零编译通知；候选 24 实体/9 材质，对照 18 实体/9 材质。契约编译只确认公开数据与参数语义，不能代替真实 Blender 编译、渲染与视觉检查。

在早期五轮几何与灯光迭代后，本轮完成三轮各向异性材质预览，最新证据在 `.deepblend/quality/benchmarks/draft-metal-lamp-anisotropic-v3/`，使用统一 renderer、Blender 5.2.1 LTS、384×288/16 samples。三机位已查看：灯罩、底座使用实际径向切线；背面机位消除了顶部世界背景边界，并为完整线缆保留画面下缘间距。早期已修正遮挡开口的 detail 机位、主杆与罩口的局部相交及电线埋地。

最新候选真实编译为 50,875 个多边形。`geometry-checks.json` 中 8 个主要封闭实体全部边界边为 0、非流形边为 0、正体积，9 项世界空间尺寸落在声明容差内。电线实际最低 Z≈0.123 mm、脚垫最低 Z=0；弯臂顶端 Z≈455.0 mm。这些结果来自 checkpoint 的网格检查，声明的验收区间本身不作为测量结果。

## 已知限制与待检查

- 各向异性反射使用真实 Principled 模型和显式径向切线，已在 Blender 5.2.1 的独立材质片验证旋转、高光变化及保存重开一致性。它描述方向性反射，不等于模拟加工刀痕；程序噪声也不代表可测量的真实磨痕。当前方向性反射要求 Cycles。
- 内衬和灯泡是外观几何，未模拟真实散射、灯具光通量、内部接线或螺纹；不用于工程制造或照度认证。
- 弯臂使用 Blender 自动手柄；电线使用 85 点显式采样路径，并限制中心高度不小于 2.3 mm，以消除自动手柄的地面下穿。
- 相机位置与欧拉角逐通道线性插值；三个关键帧精确瞄准同一点，中间帧只是近似圆弧，8°小幅运动应视觉平滑，待动画检查确认。
- 低清检查已完成，仍需固定分辨率成品图、消融对照和完整动画复核。重点待查：拉丝纹理在 1024 像素下是否过密、灯罩高光是否出现细分条带、内衬与粗对照外壳的关系，以及 48 帧运动是否保持构图。技术通过不等于审美已验收。
